# 验收标准

## 1. 总体验收原则

### 1.1 验收层级

```
P0 (阻塞级) — 必须满足，否则系统不可用
P1 (关键级) — 必须满足，影响核心功能
P2 (重要级) — 必须满足，但可暂缓修复
P3 (建议级) — 建议满足，可后续迭代
```

### 1.2 验收通过条件

- 所有 P0 项 100% 通过
- 所有 P1 项 ≥ 95% 通过
- 无已知崩溃或数据丢失缺陷
- 官方示例谜题至少 80% 可被求解

## 3. 规则实现验收

每条规则的验收标准分三级：

| 级别 | 含义 | 测试方法 |
|------|------|----------|
| L1 基础 | 正确验证已完成的解 | 给定完整解，验证器返回正确结果 |
| L2 求解 | 求解器能在带有该规则的小型谜题上找到解 | 4×4 ~ 6×6 范围内 |
| L3 组合 | 求解器能处理该规则与其他规则的组合 | 6×6 内 2~4 条规则组合 |

### 3.1 形状池 (规则 1)

| ID | 验收项 | 级别 |
|----|--------|------|
| 1-L1-01 | 区域形状必须全部来自形状池 | L1 |
| 1-L1-02 | 形状可旋转 0°/90°/180°/270° | L1 |
| 1-L1-03 | 形状可水平/垂直翻转 | L1 |
| 1-L1-04 | 形状可重复使用（未特别说明时） | L1 |
| 1-L2-01 | 4×4 网格 + 形状池解谜 | L2 |
| 1-L3-01 | 形状池 + 精确 + 面积 | L3 |

### 3.2 玫瑰窗 (规则 2)

| ID | 验收项 | 级别 |
|----|--------|------|
| 2-L1-01 | 每种符号数量完全相等 | L1 |
| 2-L1-02 | 区域数 = 每种符号的数量 | L1 |
| 2-L1-03 | 每个区域包含全部 N 种符号各一次 | L1 |
| 2-L1-04 | 所有符号均被区域覆盖 | L1 |
| 2-L2-01 | 4×4 + 2 种符号各 2 个 | L2 |

### 3.3 异生 (规则 3)

| ID | 验收项 | 级别 |
|----|--------|------|
| 3-L1-01 | 异生标记两侧区域形状不同 | L1 |
| 3-L1-02 | 形状不同 = 无法经旋转/翻转重合 | L1 |
| 3-L2-01 | 4×4 + 异生标记 | L2 |

### 3.4 双生 (规则 4)

| ID | 验收项 | 级别 |
|----|--------|------|
| 4-L1-01 | 双生标记两侧区域形状相同 | L1 |
| 4-L1-02 | 形状相同 = 可经旋转/翻转重合 | L1 |
| 4-L2-01 | 4×4 + 双生标记 | L2 |

### 3.5 精确 (规则 5)

| ID | 验收项 | 级别 |
|----|--------|------|
| 5-L1-01 | 所有区域面积等于给定值 | L1 |
| 5-L2-01 | 6×6 + 精确=4 | L2 |

### 3.6 拼块 (规则 6)

| ID | 验收项 | 级别 |
|----|--------|------|
| 6-L1-01 | 带拼块标记的格，其区域形状 = 标记形状 | L1 |
| 6-L1-02 | 标记形状可旋转/翻转后匹配 | L1 |

### 3.7 混合 (规则 7)
