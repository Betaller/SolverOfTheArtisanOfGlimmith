- 范围：`rsolver/src/`（Rust 求解器）、`src/`（Python 前端）、`web/`（Vue3 前端）
- 方法：多 agent 静态扫描 + 逐条源码核对（READ 确认），剔除误报。
- 重要背景：Python 层 `src/solver/base.py:_verify_answer` 对每个求解答案独立调用

  直接产生用户可见的错误输出或数据损坏。

## 严重程度：HIGH（Rust 求解器 soundness 缺陷 — 被 Python 独立校验兜底，但确实丢解）

### H1. `rsolver/src/solver/aog/empty.rs:244` — `empty_block_line_count` 过度剪枝（UNSOUND）
对块线图每个连通分量累加 `min(c1, c2)`（二分图两色类较小者）。但「必须排除的格数」应为
**最小顶点覆盖** `τ = ν`（最大匹配），而 `min(|A|,|B|) ≥ τ`（等号仅当匹配饱和小侧）。当
`ν < min(|A|,|B|)` 时代码多扣排除格，把 `max_area_size` 压到真实可达值之下 → 合法分支被剪。
例：双星形块线图 a1–c1–c2、a2–c1、b1–c2、b2–c2，`min=3` 而 `ν=2`，12 格连通区可含 10 格
合法区却被剪到 ub=9。（已独立数学推导确认。）
**状态：待修**

### H2. `rsolver/src/solver/aog/core.rs:919` — `block` 矩形目录漏掉「竖长矩形」
仅遍历 `l*l<=size` 宽向（行=l ≤ 列=h），guard 为 `l<=n_row && h<=n_col`。`shapes_insert`
会插入其转置（竖向 h×l），而转置是否被插入**仅取决于宽向是否适配**。当竖向适配而宽向不适配
（如 5×2 板上 size=5 的 5×1 竖条）时整个形状被漏掉，且 `search.rs:1311` 对非矩形直接
`return -1` → `block` 谜题报无解。`n_row>n_col` 时所有「行数>列数」矩形都缺失（15/66 个
block 谜题属此，目前未触发仅因都不需要竖长矩形）。
**状态：待修**

### H3. `rsolver/src/solver/aog/search.rs:1311` + `core.rs:573/595` — `block` 在形状池路径上未强制
`only_rectangles` 仅在 `place_non_predifined_shape`（free 枚举，500/600 行）检查；Type1-4
预定义形状放置路径**无矩形检查**。当 `block`(→only_rectangles) 且 `shape_pool`
(→predefine_shapes_only) 同时生效，非矩形池形状被无校验放置，违反 `block`。实测 puzzle 1169
（L/J/T 形 + block）→ aog 产非法分区，被 Python `IndependentValidator` 判 `validation_failed`。
**状态：待修**

### H4. `rsolver/src/solver/edge_csp/prop.rs:1349` — 桥接迫使 Uncut 过度（UNSOUND）
`force_compass_via_bridges_and_gateways` 中，对每条 bridge：`ci_side_count < v &&
other_side_count > 0` 就 `force_uncut = true`。缺少「此桥是唯一可达路径」守卫（对比 gateway
强制 1448 行 `len()==1`、下方限额强制 1017 行 `dir_count==1`+`all_others_blocked`）。同一方向
≥2 座桥、各自不足但并集溢出时，代码把所有桥都强制 Uncut → 该方向计数超 `v` 触发 `Err(())` →
合法解「只切 A / 只切 B」不可达。
**状态：待修**

### H5. `rsolver/src/solver/mod.rs:344` — `build_solution_trusted` 跳过 `validate`
aog 是唯一不调用 `validate::validate` 的路径（其余 rose/pieces/backtrack/edge_csp 都在
`build_solution` 304 行重校验）。现有 Python `_verify_answer` 兜底，但 Rust 二进制层对 aog
自身输出零校验，是 soundness 洞的载体。（注：实测 1169 的 `aog → validation_failed` 来自
Python 层 `_verify_answer`，非 Rust 内部。）
**状态：待修**
