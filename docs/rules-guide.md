# 《The Artisan of Glimmith》游戏介绍与规则指南

> 更新日期：2026-07-27
> 基于游戏内实际机制、社区资料及多方求解器实现交叉验证。

---

## 1. 游戏介绍

### 1.1 游戏概述

**The Artisan of Glimmith**（格利米斯的工匠）是由 Lunarch Studios 开发的一款休闲解谜游戏，于 2026 年 3 月 17 日在 Steam 平台正式发布。

玩家扮演一位著名的彩色玻璃工匠，受雇于云上王国 Glimmith 的一位富商，任务是修复该地区破败的彩色玻璃艺术品。委托人的要求很特别："用什么颜色都可以，只要遵守规则。"

### 1.2 核心机制

游戏的核心机制是**区域分割**：将矩形网格沿网格线划分为若干个连通区域（拼块），每条分割线对应彩色玻璃中不同颜色玻璃之间的接缝。

每一步操作需要同时满足：

1. **网格上放置的线索**（单元格线索、边线索、顶点线索）
2. **全局规则**（适用于所有区域）
3. **预切边**（已画好的分割线必须在不同区域之间）

### 1.3 游戏区域

游戏包含多个主题区域（由易到难）：

| 区域 | 说明 |
|------|------|
| 森林入口 (Forest Entrance) | 新手关卡，介绍基本机制 |
| 城堡入口 (Castle Entrance) | 初级进阶，引入更多规则类型 |
| 市场 (Market) | 中级区域，规则组合开始出现 |
| 小镇 (Town) | 中级区域 |
| 森林 (Forest) | 中高级区域 |
| 树篱迷宫 (Hedge Maze) | 高级区域 |
| 螺旋岛 (Spiral Island) | 高级区域 |
| 秘密花园 (Secret Garden) | 专家区域 |
| 幽深花园 (Secluded Garden) | 终极挑战 |

### 1.4 游戏特色

- **手工设计**：所有关卡由人类设计师精心制作，非程序生成
- **20+ 种规则**：随着进程解锁，规则逐步叠加
- **内置关卡编辑器**：可自创谜题并分享至创意工坊
- **专家级终章谜题**：综合运用所有技巧方能通过

## 2. 基本概念

### 2.1 网格

- 游戏在一个 **2×2 到 16×16** 的矩形网格上进行
- 单元格（Cell）以 `(row, col)` 坐标标识，行列从 0 开始
- 某些单元格可能被标记为 `blocked`（不可用，不参与划分）

### 2.2 区域（拼块 / Region / Piece）

- 区域是一组**四连通**（上下左右相邻）的单元格
- 每个单元格恰好属于一个区域
- 区域不能有洞（必须是实心填充区域）
- 区域的**形状**由它包含的单元格的相对位置决定，**旋转和镜像被视为同一形状**

### 2.3 边（Edge）与边界（Boundary）

- 边是相邻单元格之间的分隔线
- `is_boundary = True` 表示该边是区域之间的分界线
- `is_boundary = False` 表示该边的两格属于同一区域
- 外边框始终是边界（网格外围）

### 2.4 线索（Clue）分类

游戏中的线索按放置位置分为三类：

| 线索类型 | 放置位置 | 含义 |
|----------|----------|------|
| 单元格线索 | 格子上 | 对该格所在区域的约束 |
| 边线索 | 两格之间的边上 | 对相邻两个区域的约束 |
| 顶点线索 | 格子的角落 | 对该顶点周围区域的约束 |

### 2.5 全局规则（Global Rule）

部分规则不在网格上放置特定线索，而是作为**全局规则卡**激活，对整个谜题中所有区域生效。

### 3.2 精确 (Precision)

**规则类型：** 全局规则

**规则描述：**
所有区域的面积必须恰好等于 N。整个谜题只能有一个 "精确" 规则生效。

此规则与单元格上的"面积数字"线索不同——后者是对单个单元格所在区域的约束，而 "精确" 是对所有区域同时生效。

**解题技巧：**
1. 先确定 N 必须能整除可用单元格总数——如果 `总格数 % N != 0`，谜题无解
2. 由此可推导出区域数量的上限和下限
3. 配合"面积数字"线索时，可交叉验证每个单元格所在区域的大小
4. 常见 N 值：2（多米诺）、3（三连块）、4（四连块）

**常见陷阱：**
- 不要与单元格上的"面积数字"线索混淆——Precision 是全局统一大小
- 1xN 的长条也算一个区域（例如在 Boxy 规则中）

---

### 3.3 形状池 (Shape Bank)

**规则类型：** 全局规则

**规则描述：**
每个区域的形状必须与形状池中的某个形状**完全匹配**。形状可旋转（0°/90°/180°/270°）和镜像共 8 种朝向。

- 形状池中的形状可**无限重复使用**
- 形状池中的形状可能不被使用（允许有剩余）
- 区域形状不能由形状池中不存在的新形状构成

**解题技巧：**
1. **面积排除法**：先计算所有区域需要的总面积（可用格数），排除面积不符的形状
2. **预置边逆推**：如果某些边已经固定为分界线，根据这些分界线形成的局部形状，反向推断必须使用的池中形状
3. **独居联动**：如果同时有"独居"规则，每个区域的形状还必须包含一个特定线索格，可据此定位形状的放置方向
4. **角落锚定**：从角落格开始尝试放置，因为角落格的自由度最低
5. **棱边探测**：边上的预切边可以大大减少可能的放置方式

**常见陷阱：**
- 形状池中的形状即使面积相同，实际布局可能完全不同（如 4 格：直条 vs L 形 vs 方块 vs T 形 vs Z 形）
- 小网格中形状放置的重叠可能比预期严重得多

---

### 3.4 玫瑰窗 (Rose Windows)

**规则类型：** 全局规则

**规则描述：**
每个区域必须包含**恰好一个**每种列出的玫瑰窗符号。例如，如果列出了 ｛A, B｝，则每个区域必须包含恰好一个含 A 符号的格和恰好一个含 B 符号的格。区域不能包含多余的玫瑰窗符号。

多个符号类型在求解器内部不作区分，仅按字母标识。

**解题技巧：**
1. **区域计数**：区域总数 = 每种符号的总出现次数。如果 A 符号出现 4 次，则恰好有 4 个区域
2. **符号距离筛选**：每种符号在该区域唯一，所以同种符号不能在同一区域——它们之间的最短路径构成隐式分界线
3. **符号配速**：当有多个符号类型时，利用两个不同符号格之间的位置关系缩小区域形状选择范围
4. **边界迫近**：当一个符号的格被"困在"角落或窄通道中时，该区域的形状选项大为减少

**常见陷阱：**
- 单符号类型的玫瑰窗同时满足"独居"的计数条件
- 符号格自身占据区域的 1 格空间，规划形状时不可忽略

---

### 3.5 双生 (Gemini)

**规则类型：** 边线索

**规则描述：**
一条边上标有 Gemini（双生）标记，表示该边**两侧的两个区域具有相同的形状**。旋转和镜像视为相同形状。同一条边两侧不能是同一个区域（即该边必定是分割边）。

**解题技巧：**
1. **形状传递**：如果区域 A 和 B 由 Gemini 相连，且 B 和 C 也由 Gemini 相连，则 A、B、C 三者形状相同（传递性）
2. **确定边界**：Gemini 边必然是分界线（非同一区域），可直接标定 `is_boundary = True`
3. **形状约束缩减**：如果 Gemini 一侧的区域形状已由其他规则确定（如形状池或拼块），另一侧也必须取同样的形状，大幅缩减搜素空间
4. **链式思维**：先找那些形状已被强约束的区域，沿 Gemini 边逐层传递形状

**常见陷阱：**
- 旋转后相同的形状算同一形状（如 L 形有 8 种朝向但全部视作同一形状）
- Gemini 连起来的区域即使形状相同，各自的放置位置和方向独立

---

### 3.6 异生 (Delta)

**规则类型：** 边线索

**规则描述：**
一条边上标有 Delta（异生）标记，表示该边**两侧的两个区域具有不同的形状**。旋转和镜像视为相同形状。同一条边两侧不能是同一个区域。

**解题技巧：**
1. **排除法**：如果一侧区域的形状已确定，则另一侧不能是同一形状——排除候选
2. **间接划分**：Delta 边也是确定的分界线
3. **配合形状池**：若形状池只有 N 个不同形状，沿 Delta 边相连的区域必须在这 N 个中选不同的
4. **配合混合规则**：如果同时有全局的"混合"规则，Delta 边是冗余信息（混合规则已经要求相邻区域形状不同），可利用此信息检验一致性

**常见陷阱：**
- Delta 只要求形状不同，不限制面积（面积可以相同也可以不同）
- 两个区域镜像形状算同一形状——不可用于满足 Delta

---

### 3.7 拼块 (Polyomino)

**规则类型：** 单元格线索

**规则描述：**
单元格上画有一个连通形状（多连块 / Polyomino），表示该格所在的**区域形状必须与这个图案完全匹配**。形状可旋转和镜像。一个区域可以包含多个相同形状的拼块线索，但不能包含不同形状的拼块线索。图案的绘制方向不重要。

**解题技巧：**
1. **绝对锚定**：这是最强的单格约束——直接确定了该区域必须是什么形状
2. **格子排除**：如果拼块线索显示一个 3 格的 L 形，那么该格所在区域不能超出 3 格周围的范围
3. **碰撞检测**：多个拼块线索分别在各自格上放置该形状，所有版本的并集就是该区域的可能范围
4. **方向试探**：对每个拼块形状尝试 8 种朝向，排除超出边界或与 `blocked` 格冲突的方向

**常见陷阱：**
- 同一区域的多个拼块线索形状必须相同（自洽性检查）
- 拼块只约束形状不约束面积，但形状本身就确定了面积

---

### 3.8 混合 (Mingle Shape)

**规则类型：** 全局规则

**规则描述：**
任意两个**边相邻**（共享一条边而不只是角碰角）的区域不能有相同的形状。旋转和镜像视为相同形状。

**解题技巧：**
1. **图着色模型**：将区域视为图的节点，相邻关系为边，给每个节点分配形状——相邻节点不能同形状。这等价于图的着色问题
2. **形状需求下限**：如果某个区域有 K 个相邻区域，则形状池至少需要 K+1 种不同形状（如果有 Shape Bank）或者该区域周围的区域不能有相同形状
3. **角落相邻不算**：A 和 B 只在对角相碰不算相邻，可以同形状
4. **逐格推断**：从形状确定的区域开始，逐步要求相邻区域选不同形状

**常见陷阱：**
- 与 Delta 冲突时，该谜题设计有误（全局"混合"必然要求所有相邻不同形状）
- 与 Match（相同）规则互斥

---

### 3.9 面积数字 (Area Number)

**规则类型：** 单元格线索

**规则描述：**
单元格上标有一个正整数，表示该格所在的**区域的总面积（单元格数）必须等于该数字**。同一区域内如果有多个面积数字，它们必须一致（即等值）。

**解题技巧：**
1. **区域边界上限**：面积数字 = N 表示该区域只有 N 格，从线索格出发 BFS 不超过 N-1 步
2. **多面验证**：若区域内有两个面积数字，必须同为 N，否则矛盾
3. **与精确联动**：如果有全局 Precision = M 且 M != N，则该格区域面积无解
4. **与范围联动**：N 必须在 Range 规则允许的范围内

**常见陷阱：**
- 面积数字确定的是格数，不是形状——形状必须通过其他线索约束
- 面积数字为 1 表示该格独自一个区域（四面全是边界）

---

### 3.10 围栏 (Palisade)

**规则类型：** 单元格线索

**规则描述：**
单元格上的围栏图标规定了该格周围**四边中哪些是边界（分界线）**。图标旋转方向不影响判断。共有六种类型：

| 围栏类型 | 边界数量 | 描述 |
|----------|----------|------|
| empty (空) | 0 | 该格四边都不是边界（完全被同区域格包围） |
| one_sided (单边) | 1 | 恰好一边是边界 |
| corner (角) | 2 | 恰好两相邻边是边界（L 形角） |
| opposite (对边) | 2 | 恰好两对边是边界（通道形） |
| three_sided (三边) | 3 | 恰好三边是边界（死胡同） |
| full (全围) | 4 | 四边全为边界（该格独立一个区域） |

**解题技巧：**
1. **直接定界**：围栏直接规定了该格的哪些边是分界线——这是最强的局部边界约束
2. **邻居联动**：如果格 A 的右边界被围栏标记为分界线，则格 A 与其右侧邻居必为不同区域——该边为 `is_boundary = True`
3. **独格检测**：全围 + 面积数字 1 必为独立格；全围 + 精确 N>1 则矛盾
4. **通道识别**：对边类型的围栏通常指示该处是一个长条形通道区域

**常见陷阱：**
- 围栏描述的是该格周围的分界线，不是区域的整体边界
- 全围 + 精确/面积数字 > 1 直接矛盾

---

### 3.11 相同 (Match)

**规则类型：** 全局规则

**规则描述：**
谜题中所有的区域必须**具有完全相同的形状**。旋转和镜像算同一形状。没有分组或子集的概念——所有区域统一一种形状。

**解题技巧：**
1. **面积总数整除**：如果总格数为 T，形状面积为 S，则 T 必须被 S 整除且区域数 = T/S
2. **平铺分析**：等价于用同一种形状平铺整个网格——可用平铺算法预计算所有可能的形状
3. **由面及形**：先从面积线索（精确、面积数字、范围）推断面积 S，再从已知的 S-连块中找出能平铺网格的形状
4. **角落强制**：角落格是该形状的"锚定点"——形状必须能放入角落且填充到所有格

**常见陷阱：**
- 与 Mismatch（相异）互斥
- 与 Mingle Shape（混合）互斥
- 形状可能很复杂（如有分支），简单形状不一定能平铺

---

### 3.12 相异 (Mismatch)

**规则类型：** 全局规则

**规则描述：**
谜题中所有的区域的形状必须**全部互不相同**。旋转和镜像算同一形状。

**解题技巧：**
1. **形状数量上限**：如果可用格总数为 T，最少格数为 1（单格），最多区域数为 T/1 = T。但这些区域的形状必须全部不同
2. **面积分组**：若全部区域形状不同，在面积相同的情况下必须有多于一种该面积的形状。例如 4 格有 5 种形状（直条/L/方块/T/Z），最多只能放 5 个面积为 4 的区域
3. **形状计数**：列出当前网格下所有可能的区域形状，找到这些形状的一个组合使得它们互不相同且恰好覆盖所有格

**常见陷阱：**
- 与 Match（相同）互斥
- 即使面积不同也不能有相同形状（如 3 格直条和 4 格直条是不同的形状）

---

### 3.13 范围 (Range)

**规则类型：** 全局规则

**规则描述：**
每个区域的面积必须在指定范围内（闭区间 `[min, max]`）。支持只设最小值、只设最大值、或两者都设。不支持不连续的多区间范围。

**解题技巧：**
1. **区域数推演**：总格数 T / max ≤ 区域数 ≤ T / min——由此确定区域数量范围
2. **极端情况检测**：如果 min = max，则等价于 Precision
3. **网格可行性检查**：最小的区域也必须满足 min，最大不能超过 max
4. **面积数字联动**：格上的面积数字必须在 Range 范围内，否则删减候选

**常见陷阱：**
- min=1 时允许单格区域
- 与 Precision 互斥

---

### 3.14 独居 (Solitude)

**规则类型：** 全局规则

**规则描述：**
每个区域必须包含**恰好一个**被计数的单元格线索/符号。被计数的内容包括：面积数字、围栏、拼块、罗盘。玫瑰窗符号仅在玫瑰窗规则只有一个符号类型时被计数。全局规则卡不算在内。

**解题技巧：**
1. **区域数锁定**：计算所有被计数的线索数量 = M，则区域数恰好为 M——这是最强的区域数确定方法
2. **每个区域一根"针"**：每个区域准确包含一个线索格，不能多也不能少
3. **区域无根则亡**：如果一个候选区域包含 0 个或 ≥ 2 个线索格，直接排除
4. **线索的辐射范围**：基于独居确定区域数后，配合"玫瑰窗"可交叉验证每种符号的区域分配

**常见陷阱：**
- 全空罗盘（无方向限制）也算一个线索格
- 望塔是顶点线索，不算在内（除非游戏内定义为放在单元格上的望塔变种）

---

### 3.15 差异化 (Size Separation)

**规则类型：** 全局规则

**规则描述：**
任意两个**边相邻**（共享一条边）的区域必须具有**不同的面积**。角落相碰不算。

**解题技巧：**
1. **面积唯一性**：与某个区域相邻的所有区域必须具有不同的面积值
2. **面积分区**：对每个区域的相邻区域集，它们的面积必须来自不同的数值
3. **小网格快速穷举**：在较小网格（如 ≤ 6×6）中，相邻关系简单，可穷举面积分布
4. **不可相邻检测**：如果两个候选区域面积相同，它们必须被其它区域隔开（不能共享边）

**常见陷阱：**
- 这个规则比较的是面积（数字），不是形状
- 面积相同但形状不同的两个区域仍不能相邻

---

### 3.16 方块 (Boxy)

**规则类型：** 全局规则

**规则描述：**
每个区域必须是一个**实心矩形**。1×N 的条形和单格都算作矩形。不允许有洞或非矩形形状。

**解题技巧：**
1. **面积因数分析**：每个区域面积必须是两个正整数的乘积（宽 × 高）
2. **行列细分**：行列方向的预切边直接决定了矩形的形成——在行方向的一系列切割必然产生矩形宽度的约束
3. **非矩形排除**：L 形、T 形、Z 形等直接排除
4. **面积交叉验证**：面积 = 素数（如 3、5、7）的区域只能是 1×N 的条（或素数 = 2 的情况可用 2×1）
5. **角落填坑**：从角落开始放矩形，因为角落格的区域形状受边框限制最严格

**常见陷阱：**
- 1×N 的细长条也是矩形——不要忽略
- 与 Non-Boxy 互斥

---

### 3.17 非方块 (Non-Boxy)

**规则类型：** 全局规则

**规则描述：**
没有任何区域可以是一个实心矩形。1×N 的条形和单格也被禁止。可以与形状池共存。

**解题技巧：**
1. **强制复杂化**：每个区域形状必须至少有一个"转弯"（即区域的包围盒中有至少一格不属于该区域，或区域的形状宽度和高度均 > 1 且非满矩阵）
2. **消除矩形候选**：在候选区域生成时直接过滤掉所有矩形
3. **面积诱导**：面积=1 的单格区域被禁止；面积=2 的多米诺也是矩形（被禁止）；面积≥4 的 L 形、T 形、Z 形等非矩形形状才合法

**常见陷阱：**
- 与 Boxy 互斥
- 面积=2 的区域永远是矩形（2×1 或 1×2），在 Non-Boxy 下不合法

---

### 3.18 砖纹 (Bricky)

**规则类型：** 全局规则（边界图约束）

**规则描述：**
禁止任何网格顶点恰好有 **4 条边界**（分界线）交汇——即不允许出现十字交叉形状的接缝点（四个区域的角碰在一起）。可以包含外边框，但外边框通常达不到 4 条分界边。

**解题技巧：**
1. **十字禁区**：每个内部顶点的分界边数只能是 0、2 或 3（当 Loopy 未启用时；若 Loopy 也启用，则只能是 0 或 2）
2. **砖瓦图样**：这要求区域边界像砖墙的纹理——边界线不能呈 "+" 字形
3. **逐顶点检查**：遍历每个内部顶点，计算围绕该顶点的 4 条边中哪些是分界线——不能恰好 4 条全是
4. **与 Loopy 联动**：Bricky + Loopy 组合意味着每个内部顶点最多 2 条分界边——这等价于"所有区域除了最大的一个之外，都必须嵌套在另一个区域的洞中"

**常见陷阱：**
- 外边界顶点通常难以达到 4 度（因为只有 2~3 条相关边），但不是绝对不可能
- 边界的计算包括**所有相邻边**，不仅是围绕某个顶点的边

---

### 3.19 环纹 (Loopy)

**规则类型：** 全局规则（边界图约束）

**规则描述：**
禁止任何网格顶点恰好有 **3 条边界**（分界线）交汇——即不允许出现 T 形交汇点。这不是要求形成环路，而是禁止 T 形连接。关心外边界。如果 Loopy 启用但 Bricky 未启用，4 度顶点仍然允许。

**解题技巧：**
1. **T 字禁区**：每个顶点的分界边数不能是 3。这意味着边界线只能是"一字直线"或"十字交叉"（需要 Bricky 时十字也被禁）
2. **环路暗示**：名虽叫"环纹"，实际不要求一定能形成环路——只是禁止分界线的端点（T 形要么有一端是 1 度的死胡同）
3. **逐顶点过滤**：与 Bricky 检查方式类似，计算边界度数
4. **与 Bricky 极值联动**：Bricky + Loopy → 每个顶点最多 2 分界边 → 区域必须嵌套

**常见陷阱：**
- 允许度为 4 的顶点（十字交叉），除非 Bricky 也启用
- 度 = 1 的顶点不是 T 形，通常由外边框造成，无需禁止

---

### 3.20 不等号 (Inequality)

**规则类型：** 边线索

**规则描述：**
一条边上标有 `>` / `<` / `^` / `v`（不等号），表示该边两侧区域的面积存在**严格的大小关系**。箭头（窄端）指向面积更小的一侧。相等是无效的。

**解题技巧：**
1. **绝对大小方向**：箭头指向较小的一侧，开口指向较大的一侧——这与数学常规符号 `>` `<` 一致
2. **差值范围**：面积差至少为 1
3. **传递链**：如果 A < B（在左边）且 B < C（在右边），则 A < C——可推断最左格所在区域最小
4. **面积推理**：结合"面积数字"和"精确"可以确定每个区域的确切面积。例如 A < B 且 A 的面积数字 = 3，B 的面积数字 = 5 → 3 < 5 成立；反过来若 B 的面积数字 = 3 则矛盾

**常见陷阱：**
- 两个面积相等的区域不能横跨不等号

---

### 3.21 差值 (Difference)

**规则类型：** 边线索

**规则描述：**
一条边上标有一个数字，表示该边两侧区域的面积之差的**绝对值**等于该数字。差值为 0 表示两侧区域面积相等（但不一定形状相同）。不规定哪边更大。

**解题技巧：**
1. **面积对推理**：如果差值 = D，则两边区域的面积组合只能是 (a, a+D) 或 (a+D, a)
2. **面积枚举**：对每个可能的 a，检查是否存在两个面积符合差值要求且同时满足其他面积约束
3. **0 值特判**：差值=0 等价于"两侧区域面积相等"（注意：这不等于形状相同！）
4. **配合精确**：如果有全局精确 = N，且差值 = D，则可能的两侧面积对是 (N, N-D) 或 (N-D, N)（如果 N-D > 0）

**常见陷阱：**
- 差值=0 只管面积相等，形状可能不同（面积相同不等于形状相同）
- 差值应用于的是相邻区域，一个区域可能与多个相邻区域有不同的面积差

---

### 3.22 望塔 (Watchtower)

**规则类型：** 顶点线索

**规则描述：**
网格顶点处标有数字（1~4），表示有**恰好多少个不同的区域**接触该顶点。一个区域接触同一顶点多次（如回弯绕回来）只算一次。"接触"的定义是围绕该顶点的单元格中有属于该区域的格。

- 1：围绕该顶点的所有现有格属于同一区域
- 2：恰好两个不同区域接触该顶点
- 3：恰好三个不同区域
- 4：恰好四个不同区域

**解题技巧：**
1. **外顶 vs 内顶**：外边界顶点最多只能有 2 个区域接触（左右或上下各一个）——值只能是 1 或 2
2. **角顶点**：四角顶点最多只有 1 个区域接触——值为 1
3. **2 值推断**：望塔 = 2 表示该顶点恰好是**两个区域的交界点**，即该处有一条分界线穿过
4. **4 值推断**：望塔 = 4 表示该顶点是四个区域交汇的十字点——仅在 Bricky 未启用时可能
5. **区域计数联动**：全局望塔的数量和分布暗示了区域的连接方式

**常见陷阱：**
- 同一个区域即使绕弯回来接触该顶点多次，也只算一次
- 外角顶点（网格四角）只有 1 个相邻格，望塔值只能为 1

---

### 3.23 罗盘 (Compass)

**规则类型：** 单元格线索

**规则描述：**
单元格上的罗盘线索统计了该格的**同一区域中的格**在四个方向半平面（北/东/南/西）中的数量：

- **北（North/Up）**：同区域中坐标 `row` 小于线索格的格数
- **南（South/Down）**：同区域中坐标 `row` 大于线索格的格数
- **西（West/Left）**：同区域中坐标 `col` 小于线索格的格数
- **东（East/Right）**：同区域中坐标 `col` 大于线索格的格数

**对角格对两个方向都贡献**（如东北角格同时算北和东）。线索格自身不计入任何方向。值为 `-1` 表示该方向无限制。全空罗盘没有方向限制，但仍被视作一个线索（对独居有效）。

**解题技巧：**
1. **区域面积 = N_北 + N_南 + N_西 + N_东 的交集大小**

   线索各方向的总和不是精确面积，因为对角格被算了两次。真正的面积需要几何计算。

2. **方向限界法**：北 = K 意味着该格北方恰好有 K 个同区域格——这限制了区域向北的延伸距离

3. **极端值推理**：
   - 东=0 且 西=0 意味着该格是它所在区域中**唯一一列**的成员（区域宽度为 1 的垂直条）
   - 北=0 且 南=0 意味着该格是**唯一一行**成员（水平条）
   - 如果 E=0, W=0, N=0, S=0 且不是全空罗盘，则区域只有一个格

4. **边界介入**：罗盘计数配合预置边——如果某个方向被预置边切割，同区域格在该方向的数量已受限于边界

5. **区域形状最大宽度/高度**：北+1+南 为区域高度，西+1+东 为区域宽度——这是一个极强的形状约束

**常见陷阱：**
- 对角格被算两次——不要直接用四个数字相加来算面积
- 如果某个方向拼写缺失，该方向不应用作限制（该方向可以是任意值）
- 全空罗盘（四个方向全部 -1 或未设置）不约束方向但仍是线索格

## 4. 规则互斥与组合

### 4.1 互斥规则对

以下规则对不能同时出现在同一谜题中：

| 规则 A | 规则 B | 原因 |
|--------|--------|------|
| 相同 (Match) | 相异 (Mismatch) | 逻辑矛盾：所有区域不能既全相同又全不同 |
| 方块 (Boxy) | 非方块 (Non-Boxy) | 互斥：不能既全矩形又全非矩形 |
| 精确 (Precision) | 范围 (Range) | 功能重叠：精确本质是 Range 的特例 (N,N) |
| 相同 (Match) | 混合 (Mingle Shape) | 逻辑矛盾：所有区域都同形状却又要求相邻不同形状 |
| 混合 (Mingle Shape) | 异生 (Delta) | 功能重叠：混合已要求所有相邻不同形状，Delta 是冗余的边级约束 |

### 4.2 常见规则组合

| 组合 | 效果 | 解题思路 |
|------|------|----------|
| 形状池 + 独居 | 每个形状恰好对应一个线索格 | 区域数 = 线索格数，从形状池中为每个线索选形状 |
| 精确 + 独居 | 区域大小统一的独居 | 格数 = 精确 × 线索格数，验证整除关系 |
| 砖纹 + 环纹 | 边界图极约束 | 每个顶点 ≤ 2 分界边 → 区域必须嵌套（环形区域） |
| 玫瑰窗 + 独居 | 多符号独居 | 每个区域包含每种符号恰好一个——复杂但确定性强 |
| 差异 + 不等号 | 边级面积双重约束 | 既有绝对大小又规定方向 |
| 拼块 + 形状池 | 形状一致性检查 | 拼块给出的形状必须在形状池中 |
| 罗盘 + 围栏 | 局部全面约束 | 罗盘限制区域范围，围栏限制局部边界——从线索格长出区域 |

## 5. 通用解题策略

### 5.1 入手指南

1. **先读全局规则** — 理解全局约束（精确、范围、独居、形状池等）
2. **算区域数** — 从独居、玫瑰窗或精确推导区域数量
3. **标定确定边** — 双生/异生/不等号/差值边都是确定的分界线
4. **锚住强约束** — 拼块（形状必须匹配）、围栏（边界必须匹配）、面积数字（大小确定）
5. **从角落生长** — 角落格最多只有 2 个方向可扩展，自由度最低
6. **逐层约束** — 用罗盘缩小区域范围，用形状池排除不符合的形状
7. **边界图检查** — 砖纹/环纹/望塔在最后阶段验证边界图一致性

### 5.2 常见陷阱

- **面积 != 形状**：面积相同不意味形状相同；形状相同不意味面积相同（不存在后者——形状确定了面积）
- **旋转和镜像**：所有形状比较规则中，8 种朝向算同一形状
- **对角不算**：角落相碰不算"相邻"——只有共享一条完整边的区域才相邻
- **边界穿越**：预切边不会改变——已被标记为分界线的边在整个求解过程中保持不变
