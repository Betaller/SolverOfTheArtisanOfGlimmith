# 12 — same-tiling 同形铺砌求解器

> 对应源码：`rsolver/src/solver/same_tiling.rs`（2026-09-22 新增）。
> 上游对照：`solver/mod.rs`（⓪ 预通路）。

## 1. 定位

全局 `same`（`validate::check_same`：所有区域同一 dihedral 形状）与两类同形特例：

- **shape_pattern 预钉 + 同形余数**（1098/1099/1100 型：N 个图案区 + 一对被
  Gemini 边锁同形的大区）；
- **homogeneous（Gemini）二分**（1248 型：一条同形边 + `precise` 锁出恰好两区）。

这些题的通病：`is_rose_capable` 明确拒绝 `same`/`different`（匹配器没有形状同一性
变量）、aog 形状库在开阔区爆炸、edge_csp 的形状同一性传播只在封口时**检查**形状而
不能**搜索**形状。same-tiling 把「同形」直接当搜索骨架，全部结果以
`validate::validate` 兜底——错解结构性无法漏出。

## 2. 区域数推导（`derive_region_count`）

四源合一（与 edge_csp 的 `structural_pieces` 同源思想），推导冲突即判无解：

1. `rose_window`：每区恰含每种符号一个 ⇒ 区域数 = 每种符号的个数；
2. `solitary`：区域 ↔ 线索格双射 ⇒ 区域数 = 线索格数；
3. `precise`：区域数 = total / A；
4. 面积去重值之和 = total ⇒ 区域数 = 去重值个数（见 11-edge-csp 的来源 4）。

## 3. 三个精确法

### 3.1 循环等距法（任意 m）

找 ψ（8 个 dihedral × 平移）使 `F = S ⊎ ψ(S) ⊎ … ⊎ ψ^{m-1}(S)`。约束是滑窗
恰一系统（s = 1_S）：

```
∀x ∈ F:  Σ_{j<m} s(ψ⁻ʲx) = 1     （窗外项钉 0）
s(y) = 0  当某个 ψⁱ(y)（i<m）离开 F
```

全式求和自动给出 |S| = |F|/m。m==2 时这就是「补集 = ψ(S)」——**0382/0960 由此
毫秒级解出**；m≥3 覆盖 0383 型循环铺砌（其三块被一个 gliding 旋转循环映射）。
系统按链求解（钉 → 翻转自由链），链自由度大时才退到 3.2。

### 3.2 m==2 伴侣对反称搜索（1248 型，2026-09-24 重写）

ψ 是**对合**且在 F 上成完美匹配时（点反射/镜面），每对 {x, ψ(x)} 恰一入 S——
**T = ψ(S) 的同余约束等价于伴侣对 XOR**（反称标注下 x∈T ⟺ ψ(x)∈S 自动成立）。
把伴侣对喂进 `must_split` 即把同余题交给完整 m=2 搜索核（对称二分支 + 全标签
visited + SAC 探测 + 双侧闭包 + fence 星 AC）：真 ψ 树 **~0.3s 落地**（1248
全解 **2.2s**，旧横截生长在 2^(50) 自由对上永远走不完）。

配套：
- **盲生长缰绳**：`has_gemini`（homogeneous/same）时 congruence-blind 的
  `m2_region_growth` 只给 2s——它看不见同余结构，曾把整份预算（1248: 120s）
  磨光饿死精确宿主；同余题归 ψ-配对搜索与窗口 CSP（3.1，任意 ψ 的补集=ψ(S)）。
- **陷阱（曾致全簇假穷尽）**：调用方预插根标签键会与 `grow_free` 入口的
  自插撞车 → 每棵树第一步即假穷尽（六棵 ψ×根树各 <20k 状态瞬间死尽，
  M2_SKIP 任何组合都救不回——症状是"传播器怎么关都没用"）。
- 旧单边横截生长（`grow_transversal`/`reachable_closure`/`bitkey`）已删。

1248（10×10、50+50、13 fence）真 ψ = (M,t) 循环序第一个过匹配检查的点反射
t=(9,9)；官方解经 Python 侧核验 ψ(S)=T 严格成立。

### 3.2b m==2 自由尺寸生长（2026-09-22，含传播化二轮）

无等距假设的 m==2 搜索：S 从根格连通生长，补集即 T，叶节点把未决格封给 T 后
过 `piece_ok` + 全量验证。**搜索空间是连通子集数（指数级）**，靠传播压树：

- **XOR 关系传播**：必分边（`is_boundary`/约束边）与 rose 符号对（每区恰含每种
  符号一个 ⟹ 同型两格必属异区）统一成二元标签关系 `force_relation(差/同)`，
  一端定另一端即强制。多类型 pin 只钉一个根格（per-type 首格钉 S 在 ≥2 类型时
  漏混合配对——全局对换只容一个代表）。
- **fence 星 AC**：构型域按已知边界位过滤后**按臂取共识**（全部幸存构型同值即
  强制，唯一构型是特例）；相邻 fence 星的共享边是一格的南臂=邻居的北臂，互相
  收窄构型域；共识臂反推与邻格的差/同关系。
- **望塔关系**：val=1 全等（EQ 星）；val=2 两格顶点=XOR 对、其余格全定同标签时
  末格翻转。计数界 `[d, d+min(u, 2-d)]` 在 `growth_prunes_ok`。
- **T-closure（已健全化）**：强制 T 格必须同属一个非 S 连通分量；**不可达 T 的
  未决格强制并入 S**。原版要求全部非 S 格从 T 种子可达——未决格本可并入 S，
  S' 长成「墙」时误杀官方分支（m=2 簇第一根因）。**S-closure（s_round）** 为
  其镜像（S 也须连通：不可达 S 的未决格强制入 T、S 断裂判死）。
- 传播写入按分支快照回滚；状态 cap 2M（到顶是预算结果而非无解证明，attempt
  记 exhausted 只是近似——cap-abort 与真穷尽在返回值上不可分，报告持续待改）。
- **visited 键 = 传播后全标签向量（2 bit/格）**：只存 S 集在对称分支下会把
  「同 S 集、不同显式 T」的异状态误合并（T 决策多知 fence 位）——假穷尽。
- **对称二分支（2026-09-23 重写）**：旧循环只分支「进 S」（T 靠传播/封盘），
  树退化成 S 子集枚举撞帽。改为逐格 **S/T 显式二分支** + 全传播。
- **失败标签探测（SAC-lite，破簇关键）**：每个未决格试两标签各自传播到不动点，
  一侧矛盾即强制另一侧。探测代价微秒级，把 1249 的树从「2M 帽打满」压到
  **285ms 直落**；0987 同法 873ms（原 40s 磨链后靠 edge_csp 兜）。分支值序用
  探测塌缩量（先试强制多的标签）。**等价类跳过**：`val==1` 望塔全等组预求 DSU
  （`eq_leader`），同类成员的探测结果与类代表全同——只探代表（1149a 类大盘
  探测成本÷类大小）；同组内出现必分对＝建表即矛盾。`val==2` 两格顶点升为
  XOR 对入 `must_split`。0987 提速至 ~500ms。
- **ring 框链 must-same（2026-09-23，1149a 破簇关键）**：框边顶点自带 2 条
  边界边（两段外框），周边两格间再多一条墙就是第 3 条 = T 字，被 ring 禁止
  ⟹ **整条周边链必同区**（`ring_frame_must_same`：四条 rim 的干净邻接全部
  入 `must_same`，`same_round` 做同关系传播，`eq_leaders` 并入等价类）。
  断链处：blocked 格、预绘/约束边（那里的 T 由叶子验证器兜底，宁可少剪不
  错杀）。1149a 的 52 格圈坍缩成 1 个标签后 val=2 望塔三缺一级联，**1.5s
  解出**（原 40s 超时）；环纹 m=2 簇全员受益：0974 16s→**650ms**、1137
  30s→**8.6s**、0987→60ms。推论对任意区域数成立（多区版宿主见 doc 13 之外
  的 aog `check_loopy`：pad=BLOCK 使框 T 在整区提交时被拒——反应式，无正向
  整链强制）。

**实测（2026-09-23 重写后）**：m=2 簇 5 题进 4 题——1249（fence 密集）
**285ms via same-tiling**、0987 **873ms**（原 edge_csp 兜底 40s+）、1137/0974
仍走 edge_csp（全链通过）；1149a 未解（纯 watchtower 因子弱、探测 1k 节点/s

作废**：格标宿主没输在范式，输在单边分支与无探测——同一宿主换搜索核即破簇。

**实测（2026-09-23 框链后）**：m=2 簇 **5/5 全解**，且全部 via same-tiling——
1149a **1.5s**（109/87 对齐官方尺寸，破簇 +1）、0974 **650ms**（原 edge_csp
16s）、1137 **8.6s**（原 edge_csp 30s）、0987 60ms、1249 173ms、1135/1392
17ms/476ms。1248（m=2 点反射横截，无 ring）仍是树规模残余。

**实测（2026-09-24 伴侣对 XOR 后）**：1248 **2.2s via same-tiling 破簇（+1）**；

### 3.3 小形状 DLX（s ≤ 8）

枚举自由 s-ominoes（s=7 共 108 个），对每个形状取 8 个 dihedral 朝向全锚放置，
过滤（落点合法 + 每种玫瑰符号恰一）后做 DLX 精确覆盖。0763（24 块七联骨牌、
m=24 无等距捷径）18ms 解出。注意叶子的覆盖检查只看**可填格**——blocked 格的
`None` 是合法状态（曾把 24/24 合法覆盖全数误拒）。

## 4. pattern 预钉 × 同形余数

`shape_pattern` 锚的落点枚举复用 `rose::puzzle_piece_pin`；互不相交完整指派后，
余数按 `remainder_per_type` 得到 m'，m'==1 直接拼整验、m'≥2 走 3.1。
入口 `total % m != 0` 的整除门**只**门控全局同形法——预钉情形各区域尺寸不等
（1100 为 35/35/6/4/6/6/4），套整除门会误杀。
