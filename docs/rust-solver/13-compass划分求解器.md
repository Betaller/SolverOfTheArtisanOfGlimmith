## 1. 为什么需要它（三重回声墙）

这 9 题（0312 / 0680–0683 / 1246 / 1258–1260）此前**全灭**，且三套实现给出同一堵墙：

| 实现 | 结局 | 根因 |
|---|---|---|
| 本项目 `pieces` | `pieces:exhausted`（假穷尽） | `generate_compass_polyominoes` 预枚举进 DLX 行表，`MAX_COMPASS_PLACEMENTS=2000` / `MAX_COMPASS_ENUM_STATES=200k` **硬截断**——`-1` 无界方向的 frontier 生长格网爆炸，真解放置被截掉后 DLX 报「无覆盖」 |
| 本项目 aog / edge_csp | 各烧满 40s 超时 | 形状库 / 边传播范式对纯区域计数题无抓手 |
| **参考 C++ AoG_Solver** | 1246 60s / 0312 30s **零输出**（对照题 1283 秒解，harness 无误） | 参考实现盲区 |

结论：这不是移植回归，是参考盲区 + 预枚举范式的结构性缺陷，**需要新算法而非移植**。

## 2. 范式：k 区域联合划分搜索

`solitary` 把区域数锁死为 `k = #罗盘线索`（标记 ↔ 区域双射，官方解 87/87 验证）。
于是问题化为：**把棋盘划分成 k 个连通区域，每区恰含一个罗盘线索，且线索的
半平面计数精确成立**。

搜索按「紧线索先、松线索后」的顺序逐区域 frontier 生长（最松的一个吃残余，
成为强制区域），全程在**收缩中的自由池**上构造放置——**没有任何预枚举列表，
因而无从截断**：

1. **半平面精确计数**：象限格同时触两个方向（NW 格既是 N 又是 W），与
   `validate::check_compass` 语义一致；`at_limit` 饱和方向禁止再进格。
2. **area 窗口联合收紧**：单线索 `lo = 1 + max(N+S, E+W)`（两轴对各自内部不交）、
   `hi = 1 + Σ(目标 ∪ 半平面可得)`；再用全局和 `Σ|R| = 可填格数` 收紧每个 `hi`。
   空半平面（棋盘边缘/blocked）钉 `Some(0)`，轴退化线索（一轴全 0 且另一轴全知）
   得精确尺寸。1259 类「全精确窗口」题由此一步锁死全部区域尺寸。
3. **AC 强制钉格**：未放置线索 j 的某指定方向若「可用格 == 目标」，这些格**必须**
   进 R_j（不动点迭代、可用池随归属收缩）；冲突即死。强制格从其他区域的生长池
   中**预留**。
4. **补全算术剪枝**（格网塌缩的关键）：`slots = cap − |cur|`，方向缺口
   `short_d` 满足 `short_d ≤ slots` 且 `Σ short ≤ 2·slots`（每步至多补 2 个
   半平面）。例：D=13,L=12 的线索起步就是 25 ≤ 26 的刀刃——整条格网被压成
   近线性链。没有这刀，1259 首块一个线索就吃满状态上限。
5. **跨线索半平面容量剪枝**：每步维护 `blocked[j][d]`（已占格 + 他人强制格 +
   当前生长集），要求 `hp_all[j][d] − blocked[j][d] ≥ t` 对所有**其他**未放置
   线索成立。当前区域吃格会毁掉他人的 cardinality 可行性——单调，一刀剪整棵子树。
6. **残余窗口检查**：每个自由连通分量必须恰好容纳其中的未放置线索，
   尺寸落在它们的联合 `[Σlo, Σhi]` 内；无线索分量是死格。
7. **最松线索 = 强制残余**：末位线索的区域 = 全部剩余自由格，直接核对计数/
   连通/窗口，不枚举。

生长用「快照回滚 + 共享 visited（256-bit 位集键）」保证每个格集合只展开一次；
全局状态预算 `MAX_GROW_STATES=3M`，触顶诚实放弃（`Walk::Aborted` **向上炸**，
不让父层继续繁殖子格网——1260 的 RAM 爆炸就是没炸穿导致的），绝不截断列表。

## 3. 声音性教训（两次假穷尽的尸检）

- **`residual_ok` 的 BFS 必须过滤已占格**：`nbrs` 是建模期的静态自由邻接，
  洪水若漫过已放置区域，整个棋盘被算成一个分量 → 官方分支被 `size > Σhi`
  误剪。松窗口题（1246）侥幸漏过、全精确窗口题（1259）当场暴露。
- **`blocked` 计数必须与 `hp_all` 同口径**：`hp_all` 排除了他人线索 home 格，
  `init_blocked` 若把「已放置线索的 home」再计一次就是双重扣除 → 容量假剪。
  两边口径必须一致（home 格一律不计）。

## 6. v2：cell-labeling CSP（`compass_label.rs`，同日第二迭代）

### 6.1 范式与动机

v1 的「逐区域集合展开」在松窗口残簇（0682/0683/1258/1260）上死于**首块枚举**
——`-1` 无界方向让面积窗口巨大，第一个区域的格网就超出状态预算。v2 把粒度翻转成
**格→区域标签**的 CSP：每个可填格一个变量，值域 = 可行标签（线索 id），约束全部
变成传播：

1. **势连通域（potential-connectivity）**：标签 `j` 对格 `x` 可行，仅当 `j` 的已占格
   经（未赋 ∪ `j`）格可达 `x`——多源位集 worklist（每格一个 `u128` 标签集）。
2. **半平面基数 AC**：`have + pool < t` 判死、`== t` 强制整池、`have == t` 禁入。
   `pool` 刻意**过近似**（域过滤只删可证不可能的标签）——过近似恰好等于 `t` 时
   每个成员都必须入选，强制才健全。
3. **象限联合计数 `joint_ok`**（本模块的关键新剪枝）：象限格**同时**供两个方向
   （NW 格既是 N 又是 W），精确小目标会被象限格**超额满足**——逐方向池检查看不
   见，联合方程组一步看穿。每条精确方向消去轴变量后对两个象限变量给出**对和界**，
   4 个象限变量 + 4 条对和界做区间传播（保守判死：`false` = 可证不可行）。
   「无 x 可行性」只依赖 x 相对线索的 **8 分区**（4 象限 + 4 轴），故按 (标签,分区)
   计算——n×k 次检查压成 8×k，实测 3.1× 提速。单精确方向的标签无联合效应
   （退化为逐方向池检查），直接跳过（大 k 题的白捡）。
4. **尺寸窗**：live `sz + potential ≥ lo`、`sz ≤ hi`、剩余格精确覆盖。
5. **可桥接性（joinability）**：每个标签的已占格必须落在同一（未赋 ∪ 标签）连通
   量里；未赋为零时这就是最终连通性，错误合并到叶子才死、绝不会漏成错解。

搜索：**只分支前沿格**（贴着已占格——树序交错定理保证完备：每区域从线索做生成树，
按父先子后的交错顺序赋值，每步都落在前沿上），MRV 取格，值序 = 邻接质量优先
（区域是连贯斑块；跳跃式取格会把蛇形格伪装成"远端"毁掉局部性信号，见 6.2）+
**配额紧度**破平（格若落在某标签的精确半平面内，`pool−short` 最小者优先——固定
配额里的格远比自由方向"想要"该标签；作次键，作主键实测全面变差）+ slack 紧者
优先 + id（全确定性，`Vec` 无 `HashMap`）。

### 6.2 启发式的实测教训（向导统计法）

给官方解写「向导搜索」（每步只走官方标签）+ 逐步打印值序排名，是定位搜索病灶的
利器。三轮值序实验的结论：

- **首选值几乎总是对**（紧 slack 序下 avg-rank 1.04），但 DFS 的病理不在错误次数
  而在**错误分支死得慢**：根节点一处 rank-5/6 的误排就能让 4M 节点帽子烧穿。
- 「最松 slack 优先」被数据一票否决（永久松动的残余-eater 标签污染首选）。
- 表面上的 S1「j2/j5 不可区分对称」与 S31「蛇尾远端格」都是 **MRV 跳跃式取格的
  人工产物**——换成前沿取格 + 邻接优先后 0682 在 2.1M 节点内解出。蛇形区域的格
  在前沿序下总是**从自己的尾巴方向**到达，邻接信号即恢复正确。
- **配额紧度（`pool−short`）只能当次键**：作主键三题误排全面变差
  （0682 17→26、0683 22→40、1258 42→73）；作次键（邻接主键 + 配额破平）最优——
  0682/0683 的 max-rank 5/7→**2/4**，1258 avg 2.89→1.46。但 0683/1258 仍未解：
  剩余差距是**错误子树死亡率**（一处 rank-1 误排的错误子树就能吞掉百万级节点），
  不是偏好精度——方向是 joinability 的构造化下界（桥接 MST/0-1 BFS 距离储备）与
  关节格强制，见 §6.3。
- 单个启发式都有反例（邻接-质量 vs 邻接-家、配额紧度 vs 蛇形远端），**互相矛盾
  的信号只在「前沿取格 + 邻接优先 + 启发式仅作排序不作剪枝」的组合下才稳定**。

### 6.4 残簇攻坚实验（2026-09-23，全部证伪已回退）

§6.2 预言的两个方向（joinability 构造化下界 + 关节格强制）与 m=2 破簇器
（SAC-lite）都做了落地实验，**均未破残簇且各有代价，已整体回退**。数据：

| 变体 | 0683 节点（~48-138s v2 内） | 速率 | 簇代价 | 结果 |
|---|---|---|---|---|
| 基线 | 14M / 60s | 233k/s | 0682 17.4s | 未解 |
| + 桥接下界 + 唯一枢纽强制 | 25.9M / 138s | 188k/s | 0682 22.2s（+28%） | 未解 |
| + 浅层（depth<3）值存活探测 | —（60s 测试预算） | ~同 | 0682 24.2s | 未解 |
| + 全深度二元域 SAC | 6.4M / 48s | 133k/s | 未测完 | 未解 |

设计与证伪点（重建成本低，代码在实验提交历史/本节描述足够复现）：

1. **桥接下界**（sound）：j 的 j-only 分量连通所需新 j 格 ≥ max 成对 0-1 BFS 距离
   （G_j = 未赋 ∪ j，未赋格代价 1；两分量时恰等）。`sz+d > hi` 判死。**证伪点：
   松窗口簇 hi 巨大，判死从不触发**——lb 只对紧窗口有效（1258 的 0 目标线索其实
   紧，但残余-eater 全 -1 线索拖垮全局）。
2. **唯一枢纽强制**（sound）：两分量、所有最短桥过同一未赋格 x、且预算恰为 d
   （旁路 ≥ d+1 超预算）→ 强制 x∈j。触发面太窄。
3. **值存活探测 / 二元域 SAC**（sound）：分支前对候选值跑 fixpoint 存活性过滤 /
   逐二元格试双值强制幸存者（m=2 的破簇形态）。**证伪点：m=2 破簇器不迁移**——
   0683 的错误子树不被 fixpoint 级矛盾杀死（全深度 SAC 后仍 6.4M 节点不收敛），
   死因在**晚叶子**（尺寸窗/合并完成时）或 ≥3 元域选择（二元 SAC 够不着）。
   套件 14.8s→25s、0682 +28-40% 的代价买不到坍缩，负 ROI。

**结论**：残簇的下一步不在传播/探测增强，而在 ①错误子树的**晚死因提前**（叶级
尺寸窗/连通合并的早期化——比如余数精确覆盖的增量界）或 ②三体/多元域的联合
剪枝（≥3 元选择上的 arc/lookahead）。0683 的 `-1` 残余-eater 标签使 hi 松弛是
结构性前提——任何「界比较」类剪枝在此先天失效，只有**等式类**约束（0 目标
半平面排除、象限联合计数）真的在咬。

### 6.5 预绘墙 must-differ 补丁（2026-09-24，1093 顺带修复）

模型的 `nbrs`（可连邻接）排除预绘墙两侧——但这只把墙当**连通断开**：两个墙侧
格仍可绕行相连，同一标签照样通过 `joinable`（潜在连通）。而预绘墙的语义是
**两侧必属异区**（`is_boundary=True forces different region ids`），与连通路径
无关。1093（`puzzle_piece+compass+solitary`）的 `(3,1)-(4,1)` 正是这种绕行同
标签，直到 `validate` 兜底才被打回——搜索白做一次完整求解。

修复：`Model.wall_pairs`（自由-自由预绘墙对，`precompute_wall_pairs`）+
`base_domains` 域过滤（墙邻已派标签从域中剔除）。纯 compass 类零行为变化的
理由：validate 本来就拒跨墙同区，该过滤只是把拒绝从叶子提前到域（健全剪枝）。

另：`Model::build_excluding`（pp-pin 余数交接用）把预钉格当不可填——不进标签、
不计半平面（预钉区是"他区"）。

### 6.6 残簇攻坚二轮：桥过滤 + 走廊强制（2026-09-24，节点 −30~70%，残簇仍未解）

死因画像（`#[cfg(test)]` 计数器，tmp_diag 测试）先立功：0683 的 6M 节点 **70% 死在
`joinable`（连通）且集中在 64-79 已派**——即「桥格先被划给别的标签、连通死亡到
很晚才显形」。三项改进：

1. **域感知桥过滤**：`compute_can`/`joinable` 的桥格从「全部未派」收窄为
   「域含 j 的未派」——永远进不了 j 的格不能当 j 的桥（域只减不增，陈旧超集
   只弱化首轮，声音）。0683 25s 节点 6.0M→4.7M。
2. **单连通走廊强制（本轮关键）**：把 j 的已派格切成纯 j 连通分量，统计每座
   桥触到哪些分量——**某分量只被一座桥触到 ⇒ 该桥强制入 j**（否则该桥溜去别的
   标签、连通死亡在 40+ 步后才显形）；零桥分量 ⇒ 立判死。0683 25s 节点
   **4.7M→1.3M（−73%）**，死亡分布从桶 4 移向桶 5/6（近叶——树在逼近全解态）。
3. **exact-cover 帽取池域 + 成对 Hall**：`size_step` 的 cap 改 `min(hi-sz, |pot|)`
   （-1 残余标签的静态 hi 不再虚增）；成对 Hall（域对池 ≥ 双侧 lo）——实测中性
