## 1. 拉格朗日松弛 —— 连通性从硬约束到软惩罚

### 1.1 核心思想

当前求解器最大的困难是**连通性约束**。每个区域必须是 4-连通子图——这使问题从
"集合划分"变成了"连通子图划分"，复杂度跃升。

拉格朗日松弛的思路：

```
原始问题 (P):
  min  0  (可行性问题)
  s.t. 每个格子属于恰好一个区域       (partition)
        每个区域连通                   (connectivity) ← 难！
        所有区域满足形状/面积/符号约束

松弛问题 (LR_λ):
  min  Σ_k λ_k · disconnect_penalty(k)  (松弛目标)
  s.t. 每个格子属于恰好一个区域
        所有区域满足形状/面积/符号约束
        (连通性被移除，变为目标中的惩罚项)
```

其中 `λ_k ≥ 0` 是拉格朗日乘子，`disconnect_penalty(k)` 是区域 k 的"断开程度"
（如：连通分量数 - 1、或不属于最大连通分量的格子数）。

### 1.2 为什么这有用

**松弛问题 (LR_λ) 远比原始问题简单**。没有连通性约束后，问题退化为：
- 将格子分配到区域（满足 partition）
- 每个区域满足面积/形状/符号约束
- 不需要检查区域是否连通

这本质上是一个**集合划分问题 + 局部约束**，求解难度大幅降低。

**拉格朗日对偶**给出原始问题的下界：
```
LD = max_{λ≥0} min_{可行赋值} Σ_k λ_k · disconnect_penalty(k)
```

若 LD > 0，则原始问题不可行（可以安全剪枝）。若 LD = 0 且松弛解恰好连通，
则找到了原始问题的解。

### 1.3 集成方式：搜索引导而非替代

不试图求解完整的拉格朗日对偶（这本身也是 NP 难的），而是用**乘子的近似值**
指导搜索：

```
阶段 1（预处理）：
  对每个区域，初始化 λ_k = 1
  迭代若干次：
    1. 固定 λ，求解松弛问题 → 得到一个"几乎连通"的格子分配
    2. 对每个不连通的区域，增大 λ_k（惩罚加重）
    3. 对连通的区域，减小 λ_k
  输出：每个格子的"软归属"（哪个区域最可能包含它）

阶段 2（搜索）：
  用软归属作为启发式：
    - 优先将格子分配给 λ 最高的区域（最需要连通的区域）
    - 优先处理软归属置信度最高的格子（归属明确的优先确定）
```

### 1.4 伪代码

```rust
fn lagrangian_guide(puzzle: &Puzzle) -> Vec<Vec<f64>> {
    // 返回 H×W 的"归属倾向"矩阵
    let mut lambda = vec![1.0; max_regions];  // 每个区域的乘子
    let mut affinity = vec![vec![0.0; max_regions]; H*W];

    for iter in 0..MAX_ITER {
        // 求解松弛问题（快速启发式）
        let assign = solve_relaxed(puzzle, &lambda);

        // 计算每个区域的断开程度
        for k in 0..max_regions {
            let components = count_components(&assign, k);
            let penalty = components.saturating_sub(1) as f64;
            // 次梯度更新
            lambda[k] += STEP_SIZE * penalty;
            lambda[k] = lambda[k].max(0.0);
        }

        // 记录归属倾向
        for cell in 0..H*W {
            affinity[cell][assign[cell]] += 1.0;
        }
    }
    affinity
}
```

### 1.5 可行性与风险

- **优点**：通用性强，理论上适用于所有含连通性约束的题
- **风险**：松弛问题的求解本身需要计算资源，迭代次数需要调优
- **行为影响**：只影响搜索启发式（引导回溯中的选择顺序），**不改答案正确性**
- **建议**：先在 compass+solitary 题（29 道未解）上做原理验证

## 2. 蒙特卡洛树搜索 (MCTS) —— 统计引导替代确定性回溯

### 2.1 核心思想

当前回溯是**确定性 DFS**：选择一个格子 → 尝试所有可能的区域归属 → 递归。
当约束稀疏时（compass-only、弱 rose 组合），搜索树是"宽而深"的，DFS 浪费大量时间
在无望的分支上。

MCTS 用**统计信息**引导搜索：

```
每个搜索树节点 = 一个部分赋值状态

节点存储：
  N(v)  = 访问次数
  Q(v)  = 累计"奖励"（从该状态出发找到解的次数）
  UCB1(v) = Q(v)/N(v) + C * sqrt(log(N(parent))/N(v))

迭代（重复至超时或找到解）：
  1. Selection:   从根出发，每次选 UCB1 最大的子节点，直到叶节点
  2. Expansion:   若叶节点非终止，扩展一个新子节点（尝试一种选择）
  3. Simulation:  从新节点出发，用快速随机策略（greedy heuristic）完成赋值 → 成功/失败
  4. Backprop:    沿路径回传结果，更新 N 和 Q
```

### 2.2 为什么 MCTS 适合这个游戏

| 游戏特征 | MCTS 优势 |
|---------|----------|
| 搜索树深度大（≤256 层） | MCTS 不对称地深入有希望的分支 |
| 分支因子大（每个格可归属多个区域） | UCB1 自适应地分配探索预算 |
| 约束可快速部分检查 | rollout 中用轻量检查而非完整验证 |
| 存在"容易"和"难"的区域 | MCTS 自然聚焦于关键决策 |
| 没有强启发式函数 | MCTS 不需要评估函数，靠 rollout 统计 |

对比 AlphaGo：围棋的搜索树也是宽而深的，启发式极弱。MCTS + 神经网络在围棋上
击败了所有传统方法。虽然我们不需要神经网络（rollout 策略已足够），
但 MCTS 的树搜索结构直接适用于约束满足问题。

### 2.3 快速 Rollout 策略

Rollout（随机模拟）是 MCTS 的核心。需要一个**快但合理**的策略：

```rust
fn rollout(state: &mut BacktrackState, puzzle: &Puzzle) -> bool {
    while state.undecided_count > 0 {
        let (r, c) = pick_by_mrv(state);  // 选最受限的格子
        let candidates = adjacent_regions(state, r, c);
        if candidates.is_empty() {
            return false;  // 死胡同
        }
        // 带权随机选择：倾向面积匹配、形状兼容的区域
        let rid = weighted_random_choice(&candidates, state);
        assign(state, r, c, rid);
        // 轻量中途检查（非完整验证）
        if quick_check_fail(state) { return false; }
    }
    // 完整验证仅在此处
    check_global_constraints(puzzle, state)
}
```

### 2.4 与现有回溯的关系

不是替代，是**互补**：

```
当前路由：
  aog DFS → pieces (DLX) → backtrack DFS

建议增强：
  aog DFS → pieces (DLX) → MCTS（新） → backtrack DFS（兜底）
```

MCTS 放在 DLX 和回溯之间：比回溯快（有统计引导），比 DLX 通用（不依赖形状池）。

### 2.5 集成要点

- 复用 `BacktrackState` 的 `clone` → 树节点快速复制
- 每个 rollout 超时 100ms → 每秒 10 次 rollout
- 搜索树常驻内存（节点数 = rollout 数 × 平均深度），估计 <100MB
- MCTS 找到的解需经 `IndependentValidator` 验证（与回溯一致）

### 2.6 可行性评估

- **最适场景**：约束稀疏的题（compass-only, weak rose, 大网格 mixed）
  —— 当前回溯在这些题上无剪枝、纯穷举
- **不适用**：约束密集的题（aog 秒解）—— MCTS 的 rollout 开销反而拖慢
- **风险**：MCTS 的随机性导致非确定性，同一题可能有时解出有时不；需多次运行或增大 rollout 预算
- **行为影响**：可能改变可解性（新路径），需全量回归

## 3. 谱序 (Spectral Ordering) —— 拉普拉斯特征向量格序

### 3.1 理论

网格图 G 的拉普拉斯矩阵 L = D - A：
- D = 度数对角阵（每个格子 2~4 度）
- A = 邻接矩阵

L 的特征向量满足 λ₁ = 0（常数向量），λ₂ > 0（连通图）。
**Fiedler 向量 v₂**（λ₂ 对应的特征向量）对图的顶点给出一个自然的线性序，
使得序中相邻的顶点在图上也倾向于相邻。

```
Fiedler 序的性质：
  - 将图"展开"为一条线，保留邻接关系
  - v₂ 的正负号将图分为两个"自然"半区
  - 广泛用于图划分和稀疏矩阵重排
```

### 3.2 在回溯变元选择中的应用

用 Fiedler 序替代当前的 `pick_next_cell` 的 row-major 后备：

```rust
fn spectral_order(puzzle: &Puzzle) -> Vec<(usize, usize)> {
    let grid = build_laplacian(puzzle);          // H*W × H*W 稀疏矩阵
    let fiedler = compute_fiedler_vector(&grid);  // 反幂法或 Lanczos
    let mut cells: Vec<_> = puzzle.fillable_cells().collect();
    cells.sort_by(|&a, &b| {
        fiedler[a.row * W + a.col]
            .partial_cmp(&fiedler[b.row * W + b.col])
            .unwrap()
    });
    cells
}
```

计算开销：
- 稀疏 Laplacian ≤ 256×256，Lanczos 迭代 O(|E|·k) ≈ 480 × 20 = 9600 次浮点运算
- **预处理一次，全局使用**：<1ms

### 3.3 为什么比 row-major 好

Row-major 是**任意的**，与问题的几何/约束结构无关。Fiedler 序是**图论的**：
- 格子按"在网格中的位置"平滑排列
- 相邻格子倾向于在序中相邻
- 被 blocked 格或预切边分隔的区域自然在序中分离

举例：一个 8×8 网格被预切边分为左右两半。
- Row-major：左半顶行 → 左半二行 → ... → 右半底行，区域边界在序中间
- Fiedler：左半全部 → 右半全部（切割边在拉普拉斯中表现为断连，Fiedler 自然分离）

### 3.4 可行性

- **纯启发式改进**：只改变变元顺序，不改搜索逻辑，不改答案
- **实现难度**：需引入稀疏特征值求解（`nalgebra-sparse` 或手写 Lanczos）
- **预期收益**：小幅但普适的改进（所有走回溯的题都可能受益）

## 4. 对称破缺 (Symmetry Breaking) —— 群论方法

### 4.1 当前的对称处理

- **形状级**：`dihedral_key`（`shapes.rs:32`）将 D4 群（8 个对称）的作用规范化为最小字典序
- **区域标签级**：回溯中 `next_region_id` 严格递增、回退递减（`backtrack.rs:63`），
  消除了区域编号置换对称

### 4.2 未处理的对称

**网格自同构 (Grid Automorphism)**：若谜题布局存在对称性（如方形网格 + 对称的线索摆放），
解空间也存在对称性。例如一个 90° 旋转对称的谜题，每个解可以旋转 90° 得到另一个合法解。
搜索会在对称分支上做重复工作。

**Burnside 引理**给出对称轨道数：
```
|orbits| = (1/|G|) Σ_{g∈G} |fix(g)|
```
其中 fix(g) = 被群元素 g 保持不变的解（着色）数。

**Polya 计数定理**：对无色格划分（无形状约束），区域的分配等价于格子着色问题，
Polya 定理直接给出区域分配方式数。

### 4.3 实用对称破缺

**Lex-Leader 约束**（CSP 标准方法）：

1. 检测谜题的对称群 G（网格图的自同构群，保持 blocked 格和线索位置）
2. 对每个对称 g∈G，添加约束：解 ≤_lex g(解)（解的字典序不超过其对称像）
3. 这保证只探索每个等价类中的一个解

在实际中：
- 手工设计的谜题很少有大对称群（设计师有意避免对称以增加难度）
- **但 AI 生成的谜题可能包含大量对称**，对称破缺对这些谜题至关重要
- 官方题库中，Zone3 少数题有旋转对称（如 8×8、10×10 方形且线索分布对称）

### 4.4 可行性

- **当前优先级低**：官方题库中对称题比例极小
- **对 `gen_ai_puzzles.py` 生成的题有潜在价值**
- **实现难度**：图自同构检测是 GI 问题（一般认为非 NP 完全但也不是 P），
  对 256 个顶点的网格图，实际可用 nauty/Traces 在毫秒级求解

## 5. 欧拉示性约束 —— 拓扑学视角

### 5.1 平面划分的全局约束

对于将平面划分为连通区域的任何有效方案，欧拉公式成立：

```
V - E + F = 1 + C
```

针对区域邻接图（平面图，对偶于边界图）：
- V_adj = 区域数 = K
- E_adj = 相邻区域对数（共享边界的区域对）
- F_adj = 边界图中的"面" = 边界线交汇点形成的面

对边界图（顶点为网格角点）：
```
B_V = (H+1)×(W+1)  网格顶点
B_E_boundary = 实际边界边数
B_E_total = H×(W+1) + (H+1)×W + B_E_boundary  (含非边界边)
B_F = K + 1  (K 个内部区域 + 1 个外部无界面)
```

### 5.2 Ring+Brick 特例

当 Ring+Brick 同时存在，内部顶点的边界度 ∈ {0, 2}，边界图是若干环的并集。
设为 m 个不相交的环：

```
每个环有 c_i 个顶点和 c_i 条边
总边界边数 = Σ c_i
K = m + 1   (m 个内部区域嵌套，K 个区域)
```

验证：假设有 3 个同心区域（一个最大区域包含两个不相交的内部区域）→ 2 个边界环 → 3 个区域。
与 B_F = K + 1 一致。

**推论**：对于 Ring+Brick 题，若已知：
- 某些边被强制为边界（围栏、预切边）
- 望塔规定了某些顶点被多少个区域接触
则可以用欧拉公式约束"总共有多少边界边"和"有多少个区域"。

### 5.3 可用的计数约束

```
B_E_boundary 必须是偶数（每个环的边数是偶数…不对，网格环可以是奇数长度）
→ 在网格上，每个环的长度至少为 4（2×2 方块的最小环）
→ 所以边界边数 ≥ 4m 至少有 4 条

K（区域数）与边界环数（ring+brick 下）的关系：
  K = m + 1（不含孤立区域时）

总网格顶点中，度数 > 0 的顶点数 = Σ c_i = B_E_boundary
→ B_E_boundary/2 = 边界边数的一半（因每边连接 2 顶点）= 参与边界的顶点数
```

这些关系可在搜索前给出快速必要性检查：
- 若已知边界边 ≥ 100 条，则至少 25 个区域参与边界，最多 K_max - 25 个区域独立
- 若 solitary 线索有 30 个（30 个区域），但边界边只有 20 条 → Ring+Brick 下不可能有 30 个区域

### 5.4 可行性

- **适合做预处理阶段的快速否决**
- **对纯 Ring+Brick+Watchtower 题可能有决定性帮助**
- **实现简单**：预处理算一次，不需要在搜索中反复计算

## 6. 熵序 / MRV 变元选择 —— 信息论方法

### 6.1 当前状况

`pick_next_cell`（`backtrack.rs:280-310`）的变元选择：
- 有 `area` 规则时：优先选未达标线索区域的 front 格（最小 row-major 索引）
- 否则：纯 row-major 顺序

这是**静态的**——不随搜索状态调整优先级。

### 6.2 基于域的 MRV 启发式

对每个未分配格子 c，定义**域大小** `dom(c)` = 可选归属数：

```
dom(c) = |{可归属的相邻区域}| + (c 能否开始新区域 ? 1 : 0)
```

MRV (Minimum Remaining Values)：**每次选 dom(c) 最小的格子**。

样例：
```
格子 A：只有 1 个相邻区域 → dom=1 → 优先分配（无选择余地，必须早定）
格子 B：有 4 个相邻区域 → dom=4 → 推迟分配（可以等更多信息）
```

这是 CSP 理论中最强、最广泛使用的启发式之一。

### 6.3 带权的熵模型

用**香农熵**替代域大小的朴素计数：

```
对格子 c，p(r) = 选择区域 r 的先验概率（基于面积/形状兼容度）
H(c) = -Σ p(r) log₂ p(r)
```

- 低熵 = 确定性高 = 优先分配
- 高熵 = 不确定性高 = 推迟

先验概率 p(r) 的估计：
- 面积兼容度：`p(r) ∝ 1/|target_size - current_size|`（越接近目标面积越可能）
- 形状兼容度：若形状池约束存在，`p(r) ∝ 1/|匹配的池形状数|`
- 罗盘兼容度：`p(r) ∝ 1/|罗盘边界框内的未定格数 - 罗盘要求的总数|`

### 6.4 可行性

- **纯启发式改进**：只改变选择顺序，**不改答案**
- **改动位置**：`backtrack.rs:280` `pick_next_cell` 函数
- **计算开销**：每次选择时扫描 frontier 计算域大小，O(frontier_size) ≈ O(未定格数)
- **预期收益**：在约束密集处更快收敛，在约束稀疏处无额外开销

## 7. 次模优化 —— 区域候选生成

### 7.1 理论

次模性 (Submodularity) 是组合优化中"边际效用递减"的形式化：

```
f(A ∪ {x}) - f(A) ≥ f(B ∪ {x}) - f(B)  for all A ⊆ B
```

即：向较大集合添加元素的边际收益不大于向较小集合添加元素的边际收益。

**若 f 是次模的，则最小化 f 可在多项式时间完成。**

### 7.2 区域生长中的潜在次模结构

定义 `f(S) = 格子集 S 作为区域的"不符合程度"`：

```
f(S) = α·area_penalty(S) + β·shape_penalty(S) + γ·symbol_penalty(S)
```

其中：
- `area_penalty(S) = |target - |S||` —— **模函数**（也是次模）
- `shape_penalty(S)` = S 与最接近的池形状的编辑距离 —— **可能是次模的**
- `symbol_penalty(S)` = S 中多余/缺少的符号数 —— 模函数

核心观察：区域生长过程 `f(S)` 若为次模，则**找最优区域等价于次模最小化**，
可用最小割（graph cut）在多项式时间求解。

### 7.3 实际障碍

连通性约束使问题不再是纯集合函数优化。次模最小化求出的最优 S 可能不连通。
修复方法：
- **次模 + 连通性 = 连通次模优化**，一般 NP 难
- 可将"连通化开销"加入目标，但这破坏了次模性

### 7.4 可行性子方向

在特定条件下可能有实用价值：
- **Boxy（矩形区域）**：目标区域是矩形时，次模 + 矩形约束是可解的
- **候选生成**：用次模最小化生成"松散候选"，再用 BFS 修剪为连通区域
- 当前 pieces 求解器用穷举多连块，次模方法可能在面积 > 12（当前枚举上限）时提供替代

### 7.5 结论

**有理论价值但不建议立即实施**。当前 MAX_AREA_TARGET=12 的枚举上限 + 回溯兜底
已经覆盖了实际需求。次模优化的复杂度和常数开销可能得不偿失。

## 8. 热带代数 —— 面积不等式的 (min,+) 视角

### 8.1 理论

热带半环 (ℝ ∪ {∞}, ⊕, ⊗) 定义为：
```
a ⊕ b = min(a, b)
a ⊗ b = a + b
```

在此代数下，面积不等式系统变为线性方程组：

```
a_u ≥ a_v + 1  (inequality)
  →  a_u ≤ a_v + (-1)  (在普通代数)
  →  a_u ⊕ (-1) ≥ a_v  (在热带代数)

|a_u - a_v| = D  (difference)
  →  max(a_u - a_v, a_v - a_u) = D
  →  在热带代数中对应二次约束（max 非热带线性）
```

### 8.2 面积约束系统的热带解释

不等式系统 `x_i - x_j ≤ c_{ij}` 等价于经典的最短路径问题：
- 每个变量 x_i 是一个节点
- 每个约束 `x_i - x_j ≤ c` 是一条边 j → i 权为 c

这也是**差分约束系统**（见文档 06 §4），但热带代数的视角将其统一到
更广泛的代数框架中，有利于发现新的约束传播规则。

### 8.3 实用价值

热带代数的洞察与 Bellman-Ford（文档 06 §4）完全一致——计算上无增量。
保留在这里作为**理论统一框架**：面积约束 + 边界度约束 + 着色约束
可以统一视为不同半环上的约束系统：
- 面积：热带 (min,+)
- 边界度：布尔代数 (∨, ∧)
- 着色：等式逻辑

统一理论可能启发新的混合传播算法。

## 9. 代数决策图 (ADD/BDD) —— 解空间压缩表示

### 9.1 思想

二元决策图 (BDD) 是布尔函数的规范压缩表示。
代数决策图 (ADD) 将 BDD 推广到实数域。

若将每个格子的区域归属编码为布尔向量，则**所有合法解的集合可以用 BDD 表示**。
BDD 支持高效的合取、析取、存在量词消除——即**符号化搜索**。

### 9.2 为什么不适合

- 每格区域归属需要 log₂(K) 位（K ≤ 256）→ 总布尔变量 ≥ 256 × 8 = 2048
- BDD 大小对变量序极度敏感，最坏情况指数级
- 即使编译成功，BDD 大小以 GB 计
- **仅当 K 很小时可行**（如 precise=2 意味着每个区域只有 2 格）——但这种题当前秒解

符号化搜索适用于**状态空间规整、变量交互局部**的问题（如硬件验证）。
拼图问题变量间交互密集（所有变量共享全局形状/连通性约束），不适合 BDD。

## 10. 综合评估与推荐

### 优先实施

| 优先级 | 方法 | 原因 |
|--------|------|------|
| **P0** | 熵序 MRV 变元选择 | 最轻量，不改答案，普适改进 |
| **P0** | 谱序 (Fiedler) | 预处理一次，比 row-major 好，不改答案 |
| **P1** | 拉格朗日松弛引导 | 理论最优雅，针对连通性瓶颈，需原理验证 |
| **P1** | MCTS 搜索 | 对弱约束题（compass/rose 组合）可能突破性改善 |
| **P2** | 欧拉示性计数 | 预处理快速否决，Ring+Brick 专用 |
| **P3** | 对称破缺 | 官方题收益小，AI 生成题潜力大 |
| **P4** | 次模优化 / ADD | 仅理论价值 |

### 建议实施顺序

```
Phase 1（本周可做）
├── 熵序 MRV → 改 pick_next_cell，10 行代码
└── 谱序预处理 → 改 fillable 初始排序，30 行代码

Phase 2（2-4 天验证）
├── 拉格朗日引导 → 在 compass+solitary 子集上原理验证
└── MCTS → 替代 backtrack 作为第三级（aog→dlx→mcts→backtrack）

Phase 3（后续评估）
├── 欧拉约束 → Ring+Brick 专用快速否决
└── 对称破缺 → 视 AI 生成谜题需求
```

所有方法均不影响答案正确性——它们要么是**预处理序的改变**（谱序/熵序），
要么是**搜索启发式**（拉格朗日引导/MCTS），
要么是**快速否决**（欧拉约束/对称破缺）——真正找到的解仍经由 `IndependentValidator` 验证。
