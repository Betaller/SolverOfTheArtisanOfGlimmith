## 0. 一句话结论

当前架构（aog DFS + pieces DLX + rose + backtrack）是本题的**最优范式组合**——区域划分谜题的
核心障碍是**连通性约束**，它在所有通用范式（SAT/ILP/CP）中都会退化（编码爆炸 / 松弛弱 / 传播不精确），
而手写 BFS flood-fill 是连通性的最优常数因子算法。后续优化不应"换范式"，而应在**手写 DFS 内
增强约束传播**（AC-3 级别的面积/边界传播、probing、降维分解、compass 边界框预推导）。
最大的未开发机会是 **Rust aog 参考求解器已实现但本项目尚未吸收的 probing / Tarjan 桥分析 /
compass 放置枚举 / 增长势 BFS** 等技术。

## 1. 问题与现状定位

### 1.1 问题本质

《格里米斯的工匠》要求把矩形网格（2×2 ~ 16×16）划分成若干 4-连通区域，同时满足 **22 种线索约束**
（on-cell / edge / vertex 三模）。判定版本 NP 完全（与 Fillomino/Slitherlink/Nurikabe 同族）。
最坏搜索空间 256^256（天文数字），实际性能完全取决于剪枝强度与变元排序。

### 1.2 求解器能力矩阵（当前实现）

| 求解器 | 算法 | 关键剪枝 | 短板 |
|---|---|---|---|
| **aog** | 形状目录 + DFS + 自由生长（C++ 1:1 移植，~3600 行） | ring T-junction / slash-distance / multi-char rose / palisade 增量 / compass 增量 / `empty_area_check` 8 项 | 大 rose 无尺寸约束卡住；形状库无界增长（5~7GB） |
| **rose** | 候选 BFS + MRV 精确覆盖 + wavefront 修复 | area_bounds / can_partition / 面积组合 / puzzle_piece 预钉 | 大网格候选爆炸（CANDIDATE_CAP=20000）；内存压力 |
| **pieces** | DLX 精确覆盖 | MRV 列选择 / reconstruct_and_validate | 大面积（>12）/ 多 compass 候选（>2000）跳过 |
| **backtrack** | 区域生长 DFS + MRV | sealed shape / edge area / BF 传播 / GF(2) parity / SAT 边界 / fence 增量 | 官方语料 **0/1052 从不触发**（aog 先成功） |

**关键事实**：backtrack 在官方语料从不触发，一切"在 backtrack 叶子/每节点上"的开销分析都不适用
（见记忆 `rsolver-review-findings-disproven`）。优化 aog 的收益远大于优化 backtrack。

## 2. 求解范式理论

> 本节补足 06/07/08 偏工程分析之外的理论原理论讲，使其可作为引用依据。

### 2.1 CSP 框架与约束传播

**形式化**：CSP = ⟨X, D, C⟩，变量 X、域 D、约束 C。解是满足所有约束的赋值。

**约束传播核心**：在不分支的前提下，利用约束从域中删除不可能出现在任何解中的值，直到**不动点**
（fixpoint）。域缩减算子单调递减且幂等，由 Knaster-Tarski 不动点定理保证收敛到唯一最大不动点。

**三种一致性级别**：

| 级别 | 适用约束 | 复杂度 | 本题对应规则 |
|---|---|---|---|
| **AC-3**（弧一致性） | 二元 | O(e·d²) | inequality / difference / differentiation（相邻区域面积关系） |
| **AC-4**（增量弧一致性） | 二元 | O(e·d) 摊还 | 同上，频繁回溯时收益有限 |
| **GAC**（广义弧一致性） | k-元 | O(d^k) 朴素 | rose_window（高元）/ compass（4 元+面积） |
| **PC**（路径一致性） | 三元 | O(n³·d³) | mixed（相邻区域形状不同的传递性） |

**对本题的元数洞察**：绝大多数规则是**二元或可二元化**的（面积关系、形状关系作用于相邻区域对），
但**连通性是高元且动态元数**的约束——一个区域的连通性涉及其所有成员格，成员在搜索中不断变化。
这是连通性在所有范式中都成核心困难的**根本原因**。

**最直接的迁移点**：将 inequality/difference 从"叶节点检查"改为"区域密封时的 AC-3 传播"——即
`06` §4 的 Bellman-Ford 差分约束传播。面积约束天然是差分约束系统（a_u - a_v ≤ c），Bellman-Ford
的负环检测就是 AC-3 的不动点计算，差分约束系统的特殊结构使复杂度从 O(ed²) 降为 O(VE)。**已落地**
（2026-08-07，BF_PROPAGATE 默认开启）。

### 2.2 精确覆盖与 DLX（Dancing Links）

**精确覆盖**：给定全集 U 和子集族 S，求 S 的子集 S* 使 U 中每个元素恰好被覆盖一次。NP 完全。

**Algorithm X**：回溯，每次选"被最少子集覆盖的元素"（MRV）使分支因子最小。

**Dancing Links**：用二维双向循环链表实现 O(1) 删除/恢复。删除节点 x 时只改 `x.up.down`/`x.down.up`，
x 自身指针未动，恢复时精确接回——"舞"的由来。

**复杂度**：最坏 O(2^|S|)，但实践中极高效（MRV 选列 + O(1) 操作 + 缓存友好的紧凑节点）。

**对本题的建模**（`pieces.rs` 已实现）：
- 矩阵列 = 每个 fillable cell（必须恰好被覆盖 1 次）+ 面积/形状附加列（可选列）。
- 矩阵行 = 一个形状放置（形状 + 朝向 + 锚点）。
- 候选来源：shape_pool（8 朝向平铺）/ area number（generate_polyominoes，≤12）/ compass（≥3 方向指定）。

**DLX 的理论价值**：它是"恰好覆盖"子问题的**最优常数因子**算法——任何通用 CSP/SAT/ILP 求解器
在精确覆盖子问题上都无法比 DLX 更快（DLX 每步 O(1)，通用传播器至少 O(d)）。将可精确覆盖化的
子问题（拼块/面积/指南针）交给 DLX 是正确选择。

**局限**：无形状池时候选形状数是"所有 ≤ 最大面积的多连块"（面积 12 约 5000+ 种自由多连块），
候选行爆炸。这就是 pieces 只对有形状池或面积 ≤12 启用的原因。

### 2.3 SAT/SMT 归约

**SAT**：判断 CNF 公式是否可满足。NP 完全（Cook-Levin）。

**CDCL**（冲突驱动子句学习，现代 SAT 求解器核心）：
1. **单元传播**到不动点
2. **冲突分析**：用蕴含图反向切分（1-UIP），学习一个新子句记录"导致冲突的变量组合不能再发生"
3. **非时序回溯**：回溯到学习子句中最近的未定变量所在层，跳过无关中间分支
4. **VSIDS 启发式**：按近期冲突活跃度选分支变量，指数衰减
5. **重启**：周期性回到根节点但保留学习子句

CDCL 的**学习能力**是它在极硬实例上优于基础 DLX 的关键——DLX 无学习。

**连通性的 SAT 编码——核心难点**（公认瓶颈）：

| 方案 | 子句复杂度 | 评价 |
|---|---|---|
| 有序编号（level/rank） | O(HW·K·log K) | 最通用，但可能形成环需额外约束 |
| 可达性（传递闭包） | O((HW)³) | 完全不可行（256 格 → 1.7×10^7 子句） |
| 流网络编码 | O(KHW) 变量 | 同 ILP 流编码，布尔化后爆炸 |

**结论**：连通性 SAT 编码规模 O((HW)² ~ (HW)³)，16×16 达 10^6~10^7 子句，传播效率远不如手写 BFS。

**最实际的用途**：作为**边界图子问题的快速否决器**——Ring/Brick 编码极紧凑（~2000 子句，微秒级），
在回溯中每当边界状态变化即检查拓扑可行性（`07` §4.2 设计，`prototypes.rs:sat_boundary_feasible` 已实现雏形）。
但只检查拓扑，不保障连通性。

**SMT** 增量价值主要在理论统一性（混合布尔+算术），实际性能不优于"SAT 边界否决 + Bellman-Ford 面积传播"。

### 2.4 ILP 归约

**变量**：x_{i,j,k} ∈ {0,1}（格属于区域 k）。划分约束 Σ_k x = 1，面积约束线性表达。

**连通性线性化——核心难点**，三种方案：

| 方案 | 变量数 | LP 松弛强度 | 实用性 |
|---|---|---|---|
| 单商品流 | O(KHW) | 中 | 规模可接受，big-M 松弛弱 |
| 多商品流 | O(K(HW)²) | 强 | 变量爆炸 |
| MTZ 类 | O(HW) | 极弱 | 分支树巨大 |

**形状匹配不可线性化**：shape_pool/puzzle_piece/mixed/same/different 的本质是**子图同构等价类**
（D4 变换下是否一致），是 QAP 的特例（NP 完全）。唯一 ILP 建模是形状放置变量，候选指数级。

**实用性**：小规模（≤6×6 且只有面积约束）秒级；一旦加形状约束或网格 ≥8×8，变量爆炸。官方题库
8×8~16×16，ILP 整体不实用。但**面积可行性子问题**（≤50 变量）微秒级——Bellman-Ford 同样微秒级且无外部依赖。

### 2.5 CP（约束编程）

**CP 本质**：CSP 的工业化实现，核心是**全局约束**（封装复杂组合结构的高效 GAC 传播器）：
- `all_different`（Régin 算法，二部匹配 O(k^2.5)）→ Mixed 规则
- `count`/`among` → watchtower / rose 符号计数
- `element` → compass 方向计数
- `circuit`/`tree`/`flow` → 连通性

**OR-Tools CP-SAT**：三引擎协同（SAT 学习搜索 + CP 传播 + LP 松弛边界）。

**优劣**：
- 优势：表达力强（整数变量不必布尔化）、全局约束高效 GAC、声明式建模快。
- 劣势：连通性传播不如手写 BFS 精确、形状匹配无现成全局约束（table 约束表爆炸）、常数因子大、
  可控性差（搜索策略黑箱）。

**结论**：CP 在建模速度上占优，但求解性能和可控性不如手写 DFS。最大价值是**新规则的原型验证**。

### 2.6 范式对比矩阵

| 维度 | 手写 DFS+剪枝 | DLX | SAT | ILP | CP |
|---|---|---|---|---|---|
| 连通性 | 强（BFS, O(HW)） | 不支持 | 弱（编码爆炸） | 中（流编码,松弛弱） | 中（部分传播） |
| 形状匹配 | 强（规范键+哈希,O(1)） | 强（候选即行） | 弱（枚举） | 不可（QAP） | 中（table 爆炸） |
| 性能 | 最优常数因子 | 精确覆盖子问题最优 | 边界图微秒级 | 小规模秒级 | 小规模秒级 |
| 可控性 | 最优 | 中 | 低（黑箱） | 低（黑箱） | 中 |
| 学习/自适应 | 无 | 无 | 有（CDCL） | 有（割平面） | 有（CP-SAT） |

**结论**：当前架构是本题最优范式组合。领域结构丰富（D4 规范化/BFS flood-fill/局部顶点检查/差分约束）
都有高效领域算法，常数因子远优于通用传播器。

## 3. 剪枝与搜索优化理论

### 3.1 CSP 通用剪枝范式

| 技术 | 原理 | 本题现状 | 迁移建议 |
|---|---|---|---|
| **前向检查 FC** | 赋值后立即检查相邻未赋值变量的域 | backtrack 守卫链已实现（ring/fence/watchtower/sealed） | 补 compass 半平面超限前向检查 |
| **维护弧一致性 MAC** | 赋值后全局 AC-3 传播到不动点 | 间歇性（64 步 SAT / 256 步 BF） | **事件驱动**：区域密封时即时触发面积传播 |
| **CBJ 冲突回跳** | 矛盾时跳回冲突来源变量 | 无 | 优先级低（backtrack 不触发） |
| **MRV** | 选域最小的变量（最先失败） | backtrack 已实现；aog 用 11 级优先级链 | aog 链末端加 MRV fallback；域计算加入 area/compass 约束 |
| **度启发式** | MRV tiebreak 选约束最多的变量 | row-major tiebreak | 改用 frontier adjacency count（零开销） |
| **LCV** | 选对其他变量约束最少的值（最先成功） | 固定邻居顺序 | 按 (area_closeness, fence_compatible, vertex_safe) 排序 |

### 3.2 变量模型选择

| 变量模型 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **格子→区域归属** | 连通性隐含 | 域大（≤K+1） | area/compass/rose 密集题（当前 backtrack） |
| **边→Boundary/NonBoundary** | 域小（2 值）、顶点度约束自然 | 连通性不隐含 | ring+brick+fence 密集题（BoundaryCSP，未实现） |

**混合策略**（推荐）：先用边变量模型传播 ring/brick 约束到不动点（确定尽可能多边状态），再注入
格子变量模型搜索剩余不确定性。即 `10` §3.5 BoundaryCSP 阶段 1-3。

### 3.3 逻辑推演 vs 搜索（DPLL/CDCL 范式）

理想求解循环：**unit propagation 到不动点 → 检查全定/矛盾 → 决策分支 → 回到传播**。

**本题的约束可推演性**：

| 规则 | 可推演性 | 推演规则 |
|---|---|---|
| ring+brick | 强（GF(2)+度约束传播） | 顶点度 ∈{0,2}，2 条确定 boundary → 剩余 NonBoundary；GF(2) 奇偶推导第 4 条 |
| fence | 弱（dihedral 类不固定边） | arm_count k 是不变量，但具体哪条边不确定（**已证伪 DSU 预合并**） |
| area-number | 中（面积锁定后传播） | 密封→面积定→inequality/difference 邻居上下界收紧 |
| compass | 中（边界框推演） | (N,S,W,E) → 边界框 [r-N,r+S]×[c-W,c+E] → 面积下界 1+N+S+W+E |
| solitary | 强（锚点确定） | K 个 clue 格 = K 个区域，每区域恰 1 个 clue |
| shape_pool/puzzle_piece | 弱（需完整区域形状） | dihedral 比较需区域完整，部分赋值上无法推演 |
| rose_window | 中（符号配对+距离下界） | 区域数=符号数；slash-distance 几何下界（已实现） |

**Deduction Engine 设计**（预搜索传播循环）：
```
deduction_loop(state):
  repeat until no change:
    propagate_boundary_from_regions   // 区域 ID 不同 → 边界定
    propagate_vertex_degree           // ring+brick 度约束 → 推导边状态
    propagate_area_constraints        // 密封面积 → 邻居上下界
    propagate_connectivity            // 推导出的 NonBoundary → DSU 合并
    propagate_forced_cells            // 只剩 1 个可达区域 → 强制分配
    propagate_fence_bits              // arm_count 超限 → 矛盾
```
当前步骤 2（sat_boundary_feasible）、3（BF 传播）已存在但间歇性；1/4/5/6 未实现为预搜索传播。
**关键**：步骤 4 的 DSU 合并**只对 ring+brick 推导出的 NonBoundary 成立**，对 fence 不成立（已证伪）。

### 3.4 连通性数据结构

| 数据结构 | 用途 | 本题现状 | 建议 |
|---|---|---|---|
| **DSU/Union-Find** | O(α(n)) 增量连通性 | **完全没有**，全用 BFS flood-fill | NonBoundary 边 DSU 预合并（仅 ring+brick 推导出的，**fence 不行**） |
| **割点/桥（Tarjan）** | O(V+E) 找关键连接 | 无 | 简化版：检测"单连接点"前沿格（O(frontier)），forced move |
| **可达性 flood fill** | 计算最大可扩展面积 | aog 的 `empty_area_size_range` 已用 | backtrack 的 `check_area_lower_bounds` 改用精确 flood fill（当前是乐观估计） |

**DSU 的关键边界**：
- ✅ **成立**：ring+brick 顶点度传播**推导出**的 NonBoundary 边（度约束确定，不依赖 pattern 方向）。
- ❌ **不成立**：fence_pattern 的 NonBoundary 边（pattern 是 dihedral 形状类，arm 方向不固定，两个相邻 fence 格对共享边的具体状态可合法不同——实证 puzzle 0390）。

### 3.5 对称性破除

| 对称性 | 状态 | 评价 |
|---|---|---|
| 区域标签置换 | ✅ 已落地（`next_region_id` 递增） | 消除区域编号排列对称 |
| 形状池 dihedral 规范化 | ✅ 已落地（`canonical_key` 取 8 变换最小字典序） | 形状级对称破除，成立 |
| 网格几何对称（D4）Lex-Leader | ❌ 未实现 | 官方题对称题比例极小，优先级低；AI 生成题潜力大 |
| fence_pattern DSU 预合并 | ❌ **已证伪** | dihedral 类不固定具体边 |

### 3.6 搜索空间结构

| 技术 | 适用性 | 评价 |
|---|---|---|
| **记忆化/DP 子状态去重** | 不可行 | 状态空间 256^256 ≈ 10^616，哈希开销超搜索开销 |
| **IDA*** | 不推荐 | 可行性问题无自然代价函数，无好 h(n) |
| **A*/双向搜索** | 不适用 | 目标状态未知；A* 空间 O(b^d) 不可行 |
| **分支限界** | 不适用 | 无目标函数（官方题唯一解） |
| **降维分解** | ✅ **高收益** | 确定边界分隔的子区域分别求解，指数级缩小规模 |

**降维分解**（强烈推荐）：预搜索阶段从确定边界构建连通分量，若网格被分成 K>1 个不连通子区域，
分别独立求解再合并。16×16 分解为 2 个 ~8×8，复杂度从 O(2^256) 降到 O(2^64 + 2^64)。前提是有足够确定边界。

### 3.7 预处理与不可满足早期检测

**已实现**：
- `pre_search_topology_check`：O(V) 扫描顶点检查预画边界是否违反 ring/brick。
- `empty_area_check` 面积下界：空区最大面积 < lower_bound → 无解。

**建议增加**：
1. **rose_window 符号均衡**：每种符号出现次数必须相等（≠ 区域数 → 无解）。
2. **precise 整除性**：total_fillable % N ≠ 0 → 无解。
3. **面积约束图负环**：预搜索阶段跑一次 Bellman-Ford（当前只在搜索中每 256 步）。
4. **欧拉示性约束**（`08` §5）：V-E+F=1+C，ring+brick 边界图是若干环，环数 m 与区域数 K 满足 K=m+1。
5. **compass 边界框**：框外相邻格与该区域间必为 Boundary（**高优先级，可确定大量边界边**）。
6. **solitary 锚点**：未决格只可达 1 个 clue 格 → 强制分配。

## 4. 业界做法与参考求解器

### 4.1 Nikoli 谜题家族共识

- 多数判定版本 NP 完全（Fillomino/Slitherlink/Nurikabe/Shakashaka 均有证明）。
- **业界共识**：对 Nikoli 风格谜题，**"手写 DFS + 激进剪枝"实践上常优于通用 SAT/CP**，因为：
  1. 连通性 SAT 编码膨胀严重；
  2. 谜题结构可被规则特定剪枝充分利用；
  3. SAT 求解器的通用性在这里是负担。
- 但 **SAT 的 CDCL 学习能力在极硬实例上有优势**——这是 Rust aog 用 probing 模拟单位传播的动因。
- **本题所有参考求解器都选择手写 DFS 而非 SAT 后端**，这一选择有学术和工程共识支撑。

### 4.2 通用框架

- **Simon Tatham's Puzzle Collection**：通用回溯 + 规则特定传播的两阶段（Deduce 传播到不动点 → Backtrack 猜测）。aog 的 11 级优先级变量排序 + 3 层增量检查是其强化版。
- **pzprjs/Puzzlink**：编辑器为主（渲染+交互），非求解器。JS glimmith-solver 与之哲学相反（求解器为主）。
- **学术界无统一的"on-cell + edge + vertex"三模约束框架**。JS glimmith-solver 的插件注册表是最接近的工程架构。

### 4.3 third_party/ 参考求解器技术吸收状态

**Rust aog (lifthrasiir) 是技术最先进的参考求解器**，其 probing / pair probing / Tarjan 桥分析 /
compass 放置枚举 / 增长势 BFS / 评分边选择 / 自动填充形状库等技术大部分尚未吸收。

### 4.4 连通性处理的最佳实践

Rust aog 的三件套是手写路线中处理连通性最成熟的方案：
1. `build_components` flood-fill 组件构建
2. `propagate_dual_connectivity` 对偶图桥分析
3. `check_complement_feasibility` 补集可行性检查

**而非 SAT 编码**——这印证了 §2 的理论结论。

### 4.5 硬实例攻坚的三类应对（非互斥）

**A. 更好的剪枝（当前路线）**：变量排序 + 增量检查 + 冲突学习 + probing + 拓扑剪枝 + 候选枚举交集。

**B. 换范式**：SAT+CDCL / CP-SAT / ILP / 混合范式（Rust aog 的动态策略选择是范例）。

**C. 并行**：谜题间并行（AoG_Solver 的 batch_run.sh）常见；谜题内并行少见，需小心搜索空间划分。

## 6. 已证伪方向清单（避免重复调研）

| 方向 | 证伪原因 | 来源 |
|---|---|---|
| **fence DSU 预合并 NonBoundary 边** | fence_pattern 是 dihedral 形状类不固定具体边，DSU 预合并不成立；独立 fence solver 无信息优势 | 记忆 `fence-pattern-dihedral-not-per-edge` |

| **backtrack 利用 shape_pattern 预计算** | backtrack 在 puzzle_piece 题 0 次触发，aog 原生支持 | 记忆 `puzzle-piece-optimization-research` |
| **完整 MILP/CP/SAT 整体替换** | 连通性约束需指数级编码，形状匹配是子图同构 NP 完全 | `06` §1, `07` §0 |
| **OR-Tools CP-SAT 整体求解** | 与现有搜索同构，通用传播器不如领域剪枝 | `06` §11 |
| **谱图论 Spectral** | 拉普拉斯特征值对区域验证开销大于 BFS | `06` §11 |
| **树宽 DP Treewidth** | 贝尔数 B_16 ≈ 10^10 状态空间不可行 | `06` §11 |
| **MINLP / 次模优化 / ADD-BDD** | 非凸+变量爆炸 / NP 难得不偿失 / 变量交互密集最坏指数级 | `07` §7, `08` §7,§9 |
| **region_of O(n²) / env::var 热循环缓存** | 0.094ms(0.001%) / A/B 重叠在噪声内；backtrack 0/1047 不触发 | 记忆 `rsolver-review-findings-disproven` |
| **aog 1s 预算封顶** | 65 道题被误伤（1047→983） | `official-puzzles-status` |

**关键边界**：fence_pattern 的 dihedral 类**不**固定具体边（DSU 不成立），但 **ring+brick 顶点度
传播推导出的 NonBoundary 边是确定性的**（DSU 合并成立）。这是对称性破除中"哪些成立"的核心边界。
