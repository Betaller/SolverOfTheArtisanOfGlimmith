## 0. 三个颠覆性发现（颠覆理论总纲的部分判断）

### 发现 1：backtrack 在官方语料 0/1052 从不触发

PASS 求解器分布 = aog 1040 + rose 10 + pieces 2 + **backtrack 0**。206 道 FAIL 是完整链路
跑完仍失败的题（fallback 到 backtrack，backtrack 也解不出）。

**冲击**：理论总纲 §5 路线图里大量"嵌入 backtrack 守卫链"的优化项（P0 事件驱动面积传播、
P1 大部分、P2 BF/GF(2)/顶点度传播、熵序 MRV、谱序 Fiedler）**对官方题集收益接近零**。
`prototypes.rs` 的 BF/GF(2)/SAT 三件套全部只在 `backtrack.rs` 调用，从未在 aog 调用。
优化必须**改造 aog**或在**预搜索阶段注入信息让 aog/SolitaryGrower 受益**。

### 发现 2：BF / GF(2) / sat_boundary_feasible 已落地，且文档目标题数过时

- `propagate_area_bounds`（Bellman-Ford）2026-08-07 已默认开启。

- `sat_boundary_feasible`（每 64 步）已实现。
- `block-line 二部 2-染色`已完整移植（`aog/empty.rs:168-254` 的 `empty_block_line_count`）。

**冲击**：理论总纲 §5.3 的 P2 项里，BF 差分约束传播、GF(2) 循环正交、block-line 2-染色
三项**已落地**，剩余增量价值极小（0-2 道）。文档 06/10 的"34 道""31 道"目标是优化前估计，
未反映已落地状态。

### 发现 3："mixed 33"等聚类是 Zone3 目录名，不是规则聚类

**冲击**：P2"区域邻接图列表着色(Mixed)"的目标 mixed 规则实际只有 **4 道 FAIL**（不是 33），
收益天花板极低。aog 的 `check_nearby_shape` 已做 mixed 增量剪枝。

## 2. 优化项去重与合并

### 2.1 ring 三件套 → 合并为一个递进项

理论总纲 §5 把这些拆成 P1/P2 多项，实际是同一件事的三个层次：

| 层次 | 描述 | 状态 |
|---|---|---|
| (a) 顶点度传播到不动点 | P1"ring+brick 顶点度传播到不动点" = P2"边界图顶点度弧一致性传播"（**同一件事**，06§5 与 11§5.2 描述相同算法） | 未实现（当前 `sat_boundary_feasible` 只检查矛盾不推导） |
| (b) 4-循环局部 GF(2) 检查 | P2"GF(2) 循环正交"的轻量版 | **已落地**（`check_gf2_parity`） |
| (c) 完整 GF(2) 高斯消元 | O((HW)³)≈1.7×10⁷ | 文档自评不推荐 |

**合并后**：只做 (a) 顶点度传播到不动点（需三态 Edge），(b) 已落地，(c) 不做。

### 2.2 compass 三件套 → 互补序列

| 项 | 性质 | 关系 |
|---|---|---|
| P0 compass 边界框预推导 | O(1) 几何推导（框外边=Boundary） | P1 的廉价前置/特例 |
| P1 compass 放置枚举取交集 | 小区域穷举有效放置取公共边 | P0 之后的精确推导，互补不重叠 |
| P2 拉格朗日/MCTS | 搜索策略替换 | 正交但价值存疑（见 §3） |

**合并后**：P0+P1 是互补序列，应连续做；P2 独立低优先。

### 2.3 面积传播 → 剩余价值清零

- P2"BF 差分约束传播"：**已落地**。
- P0"事件驱动面积传播"：BF 已开 + backtrack 0 触发 + aog 有 `empty_area_check` → **剩余价值极低，降级/取消**。

## 6. 核心结论

1. **理论总纲的方向判断正确**（不换范式、增强手写 DFS 内传播、吸收参考求解器技术），
   但**量化收益估计偏乐观**——部分项已落地、部分项目标题数过时、部分项因 backtrack 0 触发而价值清零。

2. **第一波四项（SolitaryGrower + compass 边界框 + aog 形状库上限 + rose visited 上限）
   是投入产出比最高的起点**，预计 +3~8 道（保守）到 +8~23 道（乐观），且除 SolitaryGrower 外
   都是低风险小改动。

3. **三态 Edge 是解锁第二波的关键基础设施**——6 项优化共同依赖，一次性投入 ~200 行，
   参考实现 `third_party/aog/src/solver/edge_state.rs` 可直接参考。

4. **两大单点突破口**：compass 25 全 timeout（#2 边界框 + #5 放置枚举）、21 OOM 集中 ring
   （#3 形状库上限 + #4 顶点度传播）。

5. **架构级警告**：在 aog 的形状放置 DFS 中嵌入边变量传播存在架构不自然——aog 按 `sp[x][y]`
   区域 ID 工作，不显式跟踪边状态；参考求解器从设计之初就是边变量原生的。每轮传播需
   "区域 ID → 推断边状态 → 传播 → 强制 → 回写区域 ID"，可能引入一致性 bug。这是第二波的最大风险。

6. **SolitaryGrower 是当前最值得立即推进的项**——代码已写（571 行 + mod.rs 路由），只需
   基准测试验证无回归 + 实测解出数。建议先跑全量基准（按 CLAUDE.md 门禁：归档 bin + bench）。
