## 1. 方法论与解析陷阱

### 1.1 规则不从官方 `type` 字段映射

官方 `type`（如 `1-area-numbers`、`9-no-rectangles`、`11-mixed-rules`）是**谜题名**，
每题混合多种规则（平均 2.1 条/题，620 题恰好 2 规则）。必须用 `convert_archive.py:build_rules`
从**线索字符 + 谜题布尔字段**归纳规则集，不能一一映射。错误映射会导致整条结论测错对象
（详见 §5 已证伪清单）。

### 1.2 线索字符语义（权威，来自 `convert_archive.py`）

| 字符 | 位置 | 语义 | 对应内部规则 |
|---|---|---|---|
| `#` | cell/h_edge/v_edge/vertex | 预切边界（`is_boundary=True`） | — |
| `\d\d`（如 `04`、`26`） | cell | 面积数字：该格所在区域面积 | `area` |
| `F0..F4,F7` | cell | 围栏：该格四边哪些是分界（F7=2 邻边） | `fence` |
| `S\d+` | cell | 拼块形状标记 | `puzzle_piece` |
| `P[1-9]` | cell | 玫瑰窗符号 | `rose_window` |
| `U D L R`（变长如 `U1DLR1`） | cell | 罗盘：四方向半平面同区域格数 | `compass` |
| `=` | h_edge/v_edge | 双生：边两侧同形状 | `homogeneous` |
| `!` | h_edge/v_edge | 异生：边两侧不同形状 | `heterogeneous` |
| `^ v < >` | h_edge/v_edge | 不等号：箭头指向面积小的一侧 | `inequality` |
| 数字 | h_edge/v_edge | 差值：\|两侧面积差\| | `difference` |
| 数字 | vertex | 望塔：该顶点接触的不同区域数 | `watchtower` |
| 谜题布尔字段 | — | `area_equals`→`precise`、`area_at_least/max`→`range`、`all_shapes_same`→`same`、`only_rectangles`→`block`、`no_rectangles`→`non_block`、`no_4_way`→`brick`、`no_3_way`→`ring`、`one_symbol_per_region`→`solitary` 等 | 各全局规则 |

### 1.3 五条解析陷阱（曾导致假结论，务必避免）

1. **多字符线索必须 token 切分**：`_parse_cell_row` 按 `|` 拆 cell 行，特判 `U`/`S` 变长。
   单字符 `grid[2r+1][2c+1]` 会把 `F3` 拆成 cell 的 `F` + v_edge 的 `3`。
2. **带线索的格子字符不是 `.`**：用 `.` 判定 cell 存在会剔除所有带线索格子，连锁错误。
   正确做法：cell 存在 = 该位置非框架字符（`+-|`）且非棋盘外空格。
3. **形状比较必须用 `src/solver/shapes.py:canonical_key`**（dihedral 8 朝向取最小）。
   手写 `rot90+(c,-r)` 易漏镜像变体，Z-tetromino 两种朝向会被误判不等。
4. **fence 的实际边界要用「区域分割 + blocked」判定**，`is_boundary` 集合漏标 fence 围栏边。
5. **solution 是 3 字符步长（非 2）**：`3*c+1..3*c+3` 是 h_edge 段、`3*c` 是 v_edge 墙。

## 3. 求解器可用的二级结论（14 条，按价值排序）

### 第一梯队：搜索前锁定区域数（砍分支因子，ROI 最高）

#### O1. precise 锁定区域数 = fillable // N
- **验证**：172/172 成立，且 `区域数 == fillable // N` 整除关系 172/172 成立。
- **数据**：N 分布 `3(24) 4(53) 5(56) 6(11) 7(3) 8(3) 9(3) 10(2) 11(3) ...`，N=3/4/5 为主。
- **用法**：搜索前直接定区域数，候选区域数不符即剪。N 已知 → 单区域面积固定 → 可用面积传播。

#### O2. solitary 锁定区域数 = 被计线索格数
- **验证**：87/87 成立。被计线索格数 == 区域数。
- **被计线索类型构成**：`area_number(289) fence(262) compass(255) puzzle_piece(68)`
  （玫瑰窗仅在单类型时计入；全局规则卡不计）。
- **用法**：统计 area/fence/compass/puzzle_piece 线索格总数即得区域数，搜索前锁定。

#### O3. rose_window 锁定区域数 = 单符号出现次数
- **验证**：182/182 成立。区域数 == 每种符号的出现次数（各符号均匀等量），每区域含每种符号各 1。
- **用法**：区域数 = 任一符号类型的出现次数；每个符号格是该区域的「锚点」。

### 第二梯队：确定性剪枝（一票否决，0 容忍）

#### O4. is_boundary 边预置 DSU 不同类
- **验证**：5976 条 `is_boundary` 边（`#/=/!/</v` 等）两侧必不同区域，0 违反。
- **用法**：搜索前把所有 `is_boundary` 边两端预置 DSU 不同类，搜索中永不尝试合并。
  与已落地的 fence 增量剪枝（`docs/优化/10` §B.2、commit `cd40cab`）天然衔接。

#### O5. non_block 区域面积 ≥ 3
- **验证**：70 题 0 违反，全局最小区域面积 = 3。
- **根因**：面积 1（单格）和 2（多米诺）必为矩形，被 non_block 禁止。
- **用法**：候选区域面积 < 3 直接否。

#### O6. watchtower 外顶点取值只 1 或 2、角顶点只 1
- **验证**：39 个外边非角顶点取值集合 = {1, 2}；角顶点取值集合 = {}（官方解中角顶点不设望塔，
  即隐含为 1）。
- **内部顶点取值**：`2(1124) 1(242) 3(233) 4(58)`，1–4 均可。
- **用法**：外顶点望塔值 > 2 直接否；角顶点 > 1 直接否。

#### O7. watchtower=4 与 brick 互斥
- **验证**：34 题 watchtower=4 ∩ 96 题 brick = 0。
- **根因**：watchtower=4 要求四区域汇于一点（4 度顶点），brick 禁 4 度。
- **用法**：同题有 watchtower=4 顶点则禁 brick 的 4 度——矛盾剪枝。

### 第三梯队：组合约束的强结构（缩搜索空间）

#### O8. ring+brick 同存 ⇒ 内部顶点度只 0 或 2
- **验证**：14 题同存，内部顶点度分布 `{0: 175, 2: 910}`，**只有 0 和 2**。
- **根因**：ring 禁 3 度、brick 禁 4 度 → 每内部顶点 ≤ 2 度分界边 → 区域必须嵌套。
- **用法**：ring+brick 组合下拓扑被锁死，可专用嵌套式搜索。

#### O9. homogeneous(=) 传递闭包内同形状
- **验证**：117 题 463 边 0 违反。`=` 边连成的等价类内区域形状全同（用 `canonical_key`）。
- **等价类大小分布**：`2(268) 3(37) 4(15) 5(5) 7(1)`。
- **用法**：搜索前按 `=` 边做并查集，等价类内只需求解一个区域的形状，其余复制（传递性）。

#### O10. range 紧包络
- **验证**：120 题 range 规则 min/max 包络实际尺寸 120/120 成立（0 违反）；
  其中 **114 题实际尺寸触达 min 和 max**（紧包络）。
- **用法**：官方 range 题边界几乎总被用到——优先尝试 min/max 极值尺寸的区域，
  能更快触达约束边界。

### 第四梯队：compass 面积界（部分线索适用）

#### O11. compass 通用面积下界（任何情况都成立）
- **公式**：

  ```
  面积 ≥ max( 1,
              1+U+D  若 U,D ≥ 0,
              1+L+R  若 L,R ≥ 0,
              1+v    对每个已知方向 v )
  ```

  其中 U/D/L/R 是 compass 线索格的上/下/左/右方向半平面计数值，`-1` = 无限制（不参与任何项）。
- **验证**：全量 971 线索 0 违反。与无连通性约束的 LP 最优解完全相等（971/971，是最紧）。
  290 个线索下界 == 实际面积（紧）。
- **推导**：同区域格按线索格为原点分四轴线（a_U/a_D/a_L/a_R，只贡献单方向）+ 四象限
  （n_UL/n_UR/n_DL/n_DR，每个对角格同时贡献两方向）。
  - `U=a_U+n_UL+n_UR`，`D=a_D+n_DL+n_DR`，`L=a_L+n_UL+n_DL`，`R=a_R+n_UR+n_DR`。
  - 若 U,D 都已知：`a_U+a_D+Ndiag = U+D`（Ndiag=四象限和）⇒ 面积 = `1+U+D + (a_L+a_R≥0)` ≥ `1+U+D`。
  - 单方向 v 已知：该半平面至少 v 格 + 线索自身 ⇒ ≥ `1+v`。
- **剪枝价值**：842 个线索给 >1 的有效下界；**129 个退化为平凡 1**（55 全空 compass 四方向都 -1；
  50 单方向已知且 =0；24 已知值全 0）——语义合理但无剪枝价值。
- **可改进**：见 §4。

#### O12. compass 面积上界（仅四方向全非 -1 时成立）
- **公式**：`面积 ≤ 1 + S`，`S = U+D+L+R`，仅当四方向全非 -1。
- **验证**：74/971 = 8% 线索四方向全非 -1，0 违反，紧 13。
- **推导**：恒等式 `面积 = 1 + S − Ndiag`，Ndiag ≥ 0 ⇒ ≤ 1+S。
- **限制**：含 -1 方向时无上界（-1 方向可无限延伸，107/129 含 -1 线索违反 1+S）。

### 第五梯队：背景统计（指导策略）

#### O13. 多规则组合
- 平均 2.1 条规则/题，620 题恰好 2 规则，273 题单规则，43 题 4 规则。
- 求解器必须支持组合约束传播，单规则专用求解器需留组合接口。

#### O14. 区域数量级
- 区域数：min 2 / max 84 / 中位 9。区域数/格数中位 0.25。
- branching 因子量级参考：多数题区域数个位到十几。

## 4. compass 下界的可改进空间（未推完）

当前 O11 下界与**无连通性约束**的 LP 最优相等，但**不是真实最紧**：

- **gap 分布**（实际面积 − O11 下界）：`0(290) 1(205) 2(143) 3(101) 4(60) 5(46) ...`，
  **681/971 线索 gap ≥ 1**。
- **gap 来源**：区域必须 4-连通。对角象限（n_UL 等）的格要连到线索格，必须额外经过通路格
  （上方/左方轴线或相邻象限），这部分面积没被 8 变量 LP 计入。
- **错误尝试**：`1+max(行已知)+max(列已知)` 违反 105 个——它忽略了**对角格能同时满足一个行方向
  和一个列方向**（被双计），如 `(up=1,down=-1,left=-1,right=2)` 实际面积 3（线索格 + 右上对角格
  + 右方格），公式却给 4。
- **下一步方向**：把连通性通路格纳入建模（对角象限格的可达性要求），推出更紧的闭式或
  算法下界。候选思路：对每个有 n_UL>0 的象限，最小通路格数 ≈ ⌈√n_UL⌉ 量级（需严格证明）。

## 5. 已证伪清单（勿用）

| 结论 | 失败 | 根因 |
|---|---|---|
| `TYPE_TO_RULE` 一一映射 type→规则 | 多条结论测错对象 | 官方 `type` 是谜题名，混合多规则；如 `1-single-shape` 是 Match 不是 precise，`9-no-rectangles` 含混合线索 |
| `1-single-shape` 等 Zone1 无线索谜题作归纳样本 | 假结论 | 这些题**无任何线索**，solution 非受约束唯一解，应排除 |
| compass 方向和 +1 作**所有**线索的面积上界 | 107/129 违反 | `-1` 方向可无限延伸；修正：仅四方向全非 -1 时上界成立（O12） |
| compass `1+max(行已知)+max(列已知)` 下界 | 105 违反 | 忽略对角格双计（一个对角格同时满足行+列方向） |
