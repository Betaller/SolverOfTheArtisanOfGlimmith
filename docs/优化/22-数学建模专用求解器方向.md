# 22 · 数学建模专用求解器方向：哪些题型可数学建模 + 实现方案

> 状态：**已完成**（2026-08-14，2 个 agent 并行调研：数学建模 + 面积约束族）。
> 目标：调研哪些题型可把谜题编码成**方程与不等式系统**（GF(2) 奇偶 + 整数线性 + 度界 + 布尔），
> 用全局代数求解而非 DFS/形状枚举，并给出「数学建模专用求解器」的实现方案。
> 关联：`docs/优化/18/19/20/21`（前四轮）、`docs/rust-solver/11-edge-csp求解器.md`。
> 数据源：`results/tmp/20260814_edgecsp-full.jsonl`（186 FAIL）。

## 0. 一句话结论

**可数学建模的规则有 10 条**（ring/brick/watchtower/compass/area/precise/range/difference/
inequality/fence），分别映射为**整数度界、GF(2) 奇偶、整数线性（不）等式（Bellman-Ford 差分系统）、
布尔 dihedral 约束**——**没有一条是纯 GF(2) 可解的**（compass/area 是整数加法）。但**「数学求解器」
的正确形态不是独立新模块，而是 edge_csp 传播内核的「全局代数补全」**：补 ParityUF（~73 行）+
watchtower 顶点奇偶/配置枚举（~420 行）+ 全局 Bellman-Ford（~100 行）+ compass 放置枚举（~380 行），
合计 ~950 行零依赖移植。参考实现证明**传播不能单独解完一题**（到不动点后必接搜索），所以「无搜索
秒解」只能解个位数到 ~10 道，真正收益是「传播增强 → 搜索剪枝 → 超时题在预算内搜完」，整体预计
新解 **8~15 道**。**SAT/ILP 不划算**（连通编码 O(HW²) 膨胀 + 丢传播结构 + 依赖冲突）。

## 1. 可建模规则 → 数学对象映射

| 规则 | 数学对象 | 约束表达式 | 依据 |
|---|---|---|---|
| ring | 顶点整数度界（≠3） | `deg_boundary(v) ∈ {0,1,2,4}`（禁 T） | `validate.rs` + `edge_csp/prop.rs:155-173` |
| brick | 顶点整数度界（≤3） | `deg_boundary(v) ≤ 3`（禁十字） | `prop.rs:174-188` |
| ring+brick | 顶点整数度界（≤2） | `deg_boundary(v) ≤ 2` | `prop.rs:140-154` |
| watchtower | 顶点片数 cardinality + cut 奇偶 GF(2) | 环 `pieces=max(1,k)`、树 `pieces=1+k`；奇偶 `k≡value` 仅 value=4(环)/≥3(树) 固定 | `constraints.py:450` + 参考 `watchtower.rs:5-17,356-369` |
| compass | 整数线性方程（半平面计数） | `#{同区格在 clued 格某方向} = N/S/E/W` | `constraints.py:462` + `prop.rs:915-1152` |
| area | 整数线性方程 | `Σ_{c∈region}1 = number` | `constraints.py:206` |
| precise / range | 整数线性（不）等式（全局） | `|region|=area` / `min≤|region|≤max` | `constraints.py:167/227` |
| difference | 整数线性（含绝对值） | `|area₁−area₂|=d`（两分支 ±d） | `constraints.py:432` + `prototypes.rs:62-72` |
| inequality | 整数线性不等式 | `area_smaller+1 ≤ area_larger` | `constraints.py:408` + `prototypes.rs:55-61` |
| fence | 布尔/dihedral CSP | 每 fence 格 4 边状态 ∈ pattern 二面体类 | `constraints.py:239` + `edge_csp/prop.rs:1492` |

**不可数学建模（需形状枚举/搜索）**：same/different/mixed、shape_pool/puzzle_piece、rose_window、
homogeneous/heterogeneous、block/non_block（仅 bbox 部分可建模）、solitary。

**核心难点**：区域**连通**是图性质、非线性/奇偶约束——纯数学只能解「可演绎子集」（约束唯一确定
边状态的那部分），连通性最后 `extract_regions + validate` 而非求解。

## 2. 可演绎子集评估

186 FAIL 中，**55 道**是「纯可建模」（规则全属上表十条），131 道含 rose/shape/solitary 等不可建模规则。

| 家族 | 题数 | 主导缺口 |
|---|---|---|
| watchtower 主导 | 14 | **缺 ParityUF + 顶点奇偶 + 配置枚举**（edge_csp `VertexClue.value` 至今 `#[allow(dead_code)]`，`propagate()` 无 watchtower 传播器，只做选边启发） |
| compass 主导 | 12 | **缺 compass 放置枚举**（方向计数有、但缺「方向×连通」的组件合并枚举） |
| fence 主导 | 13 | fence 传播已落地（PR#37），部分缺 watchtower/compass 联动 |
| area/ineq/diff/range | 12 | **约束本身欠定**（见 §4），非缺代数 |
| area+brick/ring | 6 | aog 形状库 OOM（`area` 不 bounding shape 库，0977/1301 等） |

其中「纯代数可全定」的候选集中在**密集 watchtower（15~100 顶点）与密集 compass（4~25 格）题，
约 20~25 道**；其余仍需少量搜索。

## 3. 数学求解器的最小闭环 = edge_csp 传播内核补全

**关键定性：数学求解器不是 edge_csp 的「无搜索版」，而是 edge_csp 传播循环的「补全」。**
edge_csp 已是「传播 + failed-literal probing + DFS 兜底」的边变量求解器；缺的是四件**全局代数**：

| 件 | 数学本质 | 工作量 | 来源 |
|---|---|---|---|
| ParityUF + 顶点奇偶传播器 | watchtower cut 奇偶 XOR 全局消元 | ~73 + ~200 行 | `third_party/aog/src/uf.rs`（现成）+ `propagation/watchtower.rs:330-533` |
| watchtower 顶点配置枚举 | cardinality（ParityUF 覆盖不到的部分） | ~220 行 | `watchtower.rs:539-758` |
| 全局 Bellman-Ford | area/ineq/diff 从组件局部启发升级为全变量差分不动点 | ~100 行 | 复用 `prototypes.rs:13-85` 模板 |
| compass 放置枚举 | 「方向计数 × 连通」耦合 | ~380 行 | `propagation/area.rs:1742-2124` |
| 顶点度界 / fence 布尔传播 | 已有 | 0 | `edge_csp/prop.rs:103-192,1492` |

**合计 ~950 行零依赖移植，有参考实现对照，风险低。**

### 关键风险：ParityUF 奇偶固定子集边界

watchtower 奇偶**只在部分顶点固定**（参考 `watchtower.rs:356-369`）：环顶点 value≤3 时 k∈{value..4}
（double-touch）奇偶不固定；value=1 环 k∈{0,1} 也不固定。所以 ParityUF 只能消 value=4(环)/≥3(树)
的 XOR 约束子集，剩余靠配置枚举兜底。**错判奇偶会制造 false contradiction**，被 validate 兜住后
表现为「无解」而非「错解」——需逐题回归。

## 5. SAT/ILP 编码可行性：不划算

- **收益**：SAT 完备（能证明无解 + 处理连通），理论覆盖全部 22 规则。
- **代价**：连通编码使变量膨胀到 O(HW²)（16×16 → 数万布尔变量+子句）；compass/area 需加法器网络；
  **丢掉参考已打磨的图结构传播**（桥分析/半平面剪枝/dihedral 剪枝）。
- **依赖**：`rsolver/Cargo.toml` 现只有 serde/serde_json；引入 minisat/cadical/z3 抬高构建门槛，
  与「单子进程 JSON 协议 + wasm cdylib」部署模型冲突。

**结论**：自研 GF(2) ParityUF + Bellman-Ford + 度界 + fence 布尔传播（零依赖 ~600 行）性价比远高于
通用 SAT。SAT 仅在「证明唯一性/无解性」的极少数题有价值，当前「多解一道」用不上。

### 6.1 实现定位

**数学建模专用求解器 = edge_csp 传播内核增强**，在 `edge_csp/prop.rs` 内新增 5 个传播器 + 新增
`rsolver/src/uf.rs`（ParityUF），**不动搜索器、不建并列新模块**：

```
rsolver/src/uf.rs                          # 新增 ParityUF（从 third_party/aog/uf.rs 移植）
edge_csp/prop.rs 内新增：
  propagate_vertex_edge_parity()           # ParityUF，条件: 有 vertex_clues
  probe_watchtower_vertex_configs()        # 配置枚举，条件: 有 vertex_clues && !in_probing
  propagate_watchtower()                   # cardinality，条件: 有 vertex_clues
  propagate_area_bounds_bf()               # 全局 Bellman-Ford，条件: 有 area/ineq/diff/precise/range
  propagate_compass_placement_enum()       # 放置枚举，条件: has_compass && max_area<=12 && !in_probing
```

### 6.2 分阶段实施（每阶段独立回归）

| 阶段 | 内容 | 覆盖 | 工作量 | 预计解出 |

| 2 | 全局 Bellman-Ford（复用 prototypes.rs 模板） | area/ineq/diff/range 12 道 | ~100 行 | +1~2 |
| 3 | compass 放置枚举 | compass 12 道 | ~380 行 | +3~6 |
| 4 | `is_edge_csp_capable` 放开 `has_edge` + `EDGE_RULES` 加 fence | fence-only/area-only 路由缺口 | ~5 行 | 前提性 |
| 5（可选） | `solve_grouped_areas`（1183） | area 1 道 | ~250 行 | +1 |
